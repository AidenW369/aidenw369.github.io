循环

4.1 循环介绍

  • 在Java中，循环是一种用来重复执行某段代码的控制结构。当你需要多次运行相同的代码块时，就可以使用循环，而不必手动重复编写这些代码。

  • Java中主要有三种循环结构：for 循环、while 循环和 do-while 循环。

  • 此外，Java 5引入了一种更简洁的遍历数组和集合的方式：for-each 循环（也叫增强型for循环）。

4.2 While循环

while循环是Java中最基本的循环结构之一，用于重复执行一段代码，直到指定的条件不再满足。

基本语法

工作原理

  1. 首先判断条件表达式是否为true
  2. 如果为true，执行循环体中的代码
  3. 执行完后再次判断条件
  4. 重复这个过程，直到条件变为false时退出循环

4.2.1 常见应用场景

1. 遍历数组

2. 用户输入验证

3. 累加计算

注意事项

  • 避免无限循环：确保循环条件最终会变为false

  • 更新循环变量：在循环体内修改条件中使用的变量

  • 使用break提前退出

  • 使用continue跳过本次循环

4.4 Do-while循环

do-while循环是一种后测试循环（先执行循环体，再判断条件），无论条件是否满足，循环体至少会执行一次。

该循环最适合那些至少需要执行一次的场景，比如用户输入验证、菜单显示等需要先执行再判断的情况。

基本语法

执行流程

  1. 执行循环体内的代码
  2. 判断while后面的条件表达式
  3. 如果条件为true，重复步骤1-2
  4. 如果条件为false，退出循环

与其他循环的对比

循环类型 特点 适用场景
do-while 先执行后判断，至少执行一次 需要至少执行一次的场景
while 先判断后执行，可能一次都不执行 可能一次都不执行的场景
for 包含初始化、条件、迭代 已知循环次数的场景

2. 菜单选择

注意事项

  1. 分号必须：while(条件)后面必须有分号 ;
  2. 避免死循环：确保循环条件最终能变为false
  3. 变量作用域：在do-while内部声明的变量，外部无法访问

4.5 for循环

for循环是Java中最常用的循环结构之一，用于重复执行一段代码特定次数。它提供了循环变量的初始化、条件判断和更新在一个简洁的语法结构中。

基本语法

  • 初始化：在循环开始前执行一次，通常用于声明和初始化循环变量
  • 条件表达式：每次循环开始前评估，为true时执行循环体，为false时退出循环
  • 更新表达式：每次循环结束后执行，通常用于更新循环变量

4.5.1 应用场景

传统计数循环

遍历数组

增强型for循环（for-each）

Java 5引入的简化版本，专门用于遍历数组和集合。

多重循环（嵌套循环）

多个控制变量

结合break和continue的循环

查找最大值

注意事项

  1. 循环变量作用域：在初始化部分声明的变量只在循环内有效
  2. 避免无限循环：确保条件表达式最终会变为false
  3. 性能考虑：不要在循环条件中重复计算不变的值

4.6 for循环案例

在 for 循环中，i++ 和 ++i 在绝大多数情况下没有实际区别，因为它们都是独立执行的语句。

核心区别

1. 返回值不同
  • i++（后置自增）：先返回i的原值，然后再将i加1
  • ++i（前置自增）：先将i加1，然后返回新值
2. 性能差异（理论层面）
  • 对于基本类型（int, long等）：现代编译器优化后没有性能差异
  • 对于C++迭代器/对象：++i通常比i++效率更高
    • i++需要保存临时副本返回原值
    • ++i直接返回自增后的值，无需临时对象

为什么for循环中没区别？

因为for循环的第三部分是一个独立的表达式语句，它的返回值被丢弃了，只执行自增的副作用。

程序员通常会遍历字符串，检查每个字符，其中for循环为最常用的方法。

4.8 嵌套循环

嵌套循环是指在一个循环语句内部再包含另一个循环语句。外层循环每执行一次，内层循环就会完整地执行一轮。

基本语法

4.8.1 常见示例

1. 打印矩形图案

2. 打印九九乘法表

3. 二维数组遍历

注意事项

  1. 性能考虑：嵌套循环会显著增加执行次数，需谨慎使用，嵌套循环的时间复杂度通常是 O(n²)、O(n³) 等，取决于嵌套的层数
  2. 代码可读性：过深的嵌套（超过3层）会使代码难以理解和维护
  3. 变量命名：内外层循环变量应使用不同的名称（通常用i、j、k）
  4. 初始化位置：内层循环的变量会在每次外层循环迭代时重新初始化

4.11 变量作用域

变量作用域（Scope）指的是变量在程序中可以被访问的范围。在Java中，根据变量声明的位置和方式，主要有四种作用域。

1. 局部变量作用域

在方法、构造器或代码块内部声明的变量。

特点：

  • 只在声明它的代码块内有效
  • 从声明位置开始，到所在代码块结束
  • 必须初始化后才能使用

2. 成员变量作用域（实例变量）

在类中、方法外声明的变量，属于对象实例。

特点：

  • 在整个类中有效（除了静态方法）
  • 有默认值（null, 0, false等）
  • 生命周期与对象相同

3. 静态变量作用域（类变量）

使用static关键字声明的变量，属于类本身。

特点：

  • 在整个类中有效
  • 所有实例共享同一个变量
  • 可以通过类名直接访问

4. 参数作用域

方法参数在整个方法体内有效。

Java中的全局作用域

严格来说，Java中并没有真正的全局作用域，这与C/C++等语言不同。Java通过类和静态成员来模拟类似全局变量的功能。
