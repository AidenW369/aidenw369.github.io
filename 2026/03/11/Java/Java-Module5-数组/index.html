数组

5.1 数组概念

数组是一种引用数据类型，用于存储相同类型的多个数据的容器。它在内存中分配连续的空间，可以通过**索引（下标）**来访问元素。

数组的特点

  • 固定长度：一旦创建，长度不可改变
  • 类型一致：所有元素必须是同一数据类型
  • 索引从0开始：第一个元素索引为0，最后一个为length-1
  • 引用类型：数组变量存储的是内存地址
  • 性能高效：内存连续，存取速度快

5.2 数组

Java中的数组是一个用于存储固定大小、相同类型元素的容器对象。

5.2.1 核心特点

  • 相同类型：数组只能存储一种数据类型（如全是 int，或全是 String）。
  • 固定长度：一旦数组被创建，它的大小（长度）就不能再改变。
  • 连续内存：数组在内存中占据一块连续的空间。
  • 索引从 0 开始：第一个元素的索引是 0，第二个是 1，以此类推。

5.2.4 数组的默认值

当使用 new 关键字创建数组后，即使没有赋值，元素也有默认值：

  • 整数类型（byte, short, int, long）：0
  • 浮点类型（float, double）：0.0
  • 字符类型（char）：'\u0000'（空字符）
  • 布尔类型（boolean）：false
  • 引用类型（类、接口、数组、String等）：null

5.2.5 常见错误

  1. 数组索引越界（ArrayIndexOutOfBoundsException）：访问了不存在的索引（如长度为5，却访问了 arr[5]）。
  2. 空指针异常（NullPointerException）：试图操作一个未初始化的数组变量。

5.10 增强型for循环

增强型for循环（Enhanced for loop），也称为”for-each循环”，是Java 5引入的一种简化数组和集合遍历的语法结构。

基本语法

主要特点

  1. 代码简洁：不需要手动管理索引或迭代器
  2. 安全性：避免了索引越界错误
  3. 可读性强：更直观地表达”遍历每一个元素”的意图

适用场景

适合：

  • 只需要读取元素，不需要修改集合结构
  • 需要遍历所有元素
  • 不关心元素的索引位置

不适合：

  • 需要修改数组或集合中的元素
  • 需要知道当前元素的索引
  • 需要在遍历过程中删除元素
  • 需要并行遍历多个集合
