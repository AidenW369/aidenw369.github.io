3.5 逻辑运算符的检测范围

在Java中，逻辑运算符主要用于操作布尔类型（boolean）的数据，即对 true 或 false 进行逻辑运算，最终返回一个布尔值结果。

它们常用于控制流程（如 if、while 语句）中，用来组合多个条件。

3.5.1 逻辑与 （&&） —— 短路与

  • 语法：条件A && 条件B
  • 结果：只有当 两个条件都为true 时，结果才为 true；否则为 false。
  • 特点（短路）：如果条件A为 false，那么整个表达式的结果已经确定为 false，条件B将不会被计算（被短路了）。这可以提高效率并避免潜在的错误。

3.5.2 逻辑或 （||） —— 短路或

  • 语法：条件A || 条件B
  • 结果：只要有一个条件为true 时，结果就为 true；只有两个都为 false 时，结果才为 false。
  • 特点（短路）：如果条件A为 true，那么整个表达式的结果已经确定为 true，条件B将不会被计算。

2.5.3 逻辑非 （!）

  • 语法：!条件
  • 结果：取相反的值。如果条件为 true，则返回 false；如果条件为 false，则返回 true。这是一个一元运算符。

在实际开发中：

  • 绝大多数情况下，使用的是 &&（短路与） 和 ||（短路或）。
  • 利用短路特性可以写出更简洁安全的代码，例如在判断一个对象是否为空之后再获取它的属性：if （obj ！= null && obj.getName（）.equals（“xxx”））。如果 obj 是 null，后半句不会执行，从而避免了空指针异常。

3.7 多条件分支语句

在Java中，多条件分支语句是指根据多个不同的条件，选择执行不同代码块的语句。

执行逻辑：

  • 程序会从上到下依次判断条件。

  • 一旦遇到一个为 true 的条件，就执行对应的代码块，然后整个 if 结构结束（后面的 else if 和 else 都不会再判断）。

  • 如果所有条件都为 false，则执行 else 中的代码（如果存在 else 的话）。

3.10.1 位运算符（二进制）

在现代计算机中，所有数据都以二进制形式存储，即 0 和 1 两种状态。计算机对二进制数据进行的运算（如加、减、乘、除）被称为位运算，即对二进制数的每一位进行操作的运算。

1. 基本位运算符

运算符优先级决定了在表达式中多个运算符共存时，哪个运算先执行。

注意：

  • 圆括号 () 可用于显式改变运算顺序，其优先级最高（相当于手动指定）。
  • 逻辑与（&&）优先级高于逻辑或（||）。
  • 赋值运算符的优先级最低，且从右向左结合，例如 a = b = c 等价于 a = (b = c)。
  • 移位运算符 >>> 是无符号右移，>> 是带符号右移。

3.12 布尔数据类型

布尔数据类型（boolean）是Java中的一种基本数据类型，用于表示逻辑值，只有两个可能的取值：

  • true（真）
  • false（假）

主要特点

  1. 大小
    • 在Java规范中没有精确定义boolean类型的大小
    • 通常依赖于Java虚拟机（JVM）的实现
    • 通常占用1个字节（8位），但实际大小取决于具体实现
  2. 默认值
    • 作为成员变量时，boolean的默认值是 false
    • 局部变量必须显式初始化才能使用

注意事项

  • 不能与数值类型相互转换
  • 布尔表达式必须返回boolean值

3.14 字符串访问操作

在Java中，字符串访问操作是指在不修改原字符串内容的前提下，获取字符串的特定信息或部分内容的操作。

由于Java中的String是不可变的（immutable），所有的访问操作都不会改变原始字符串，而是返回一个新的值或状态。

1. 获取单个字符

  • 方法： charAt(int index)
  • 作用： 返回指定索引处的 char 值。
  • 注意： 索引从 0 开始。

2. 获取字符串长度

  • 方法： length()
  • 作用： 返回字符串的长度，获取字符串中字符的总数。

3. 字符串的比较与查找

a. 查找位置

  • indexOf(int ch) / indexOf(String str)：返回指定字符或子字符串第一次出现的索引。
  • lastIndexOf(int ch) / lastIndexOf(String str)：返回指定字符或子字符串最后一次出现的索引。

b. 包含与匹配

  • contains(CharSequence s)：判断是否包含指定的字符序列。
  • startsWith(String prefix)：判断是否以指定前缀开头。
  • endsWith(String suffix)：判断是否以指定后缀结尾。

4. 获取子字符串（截取）

  • 方法： substring(int beginIndex) 或 substring(int beginIndex, int endIndex)
  • 作用： 返回字符串的子串。区间是左闭右开 [beginIndex, endIndex)。

5. 字符串的转换与状态检查

  • toCharArray()：将字符串转换为一个新的字符数组。
  • toLowerCase() / toUpperCase()：转换为小写或大写（返回新字符串）。
  • trim()：去除字符串首尾的空白字符。
  • isEmpty()：判断字符串长度是否为0。

共同特征

  1. 只读性：原字符串内容不会改变。
  2. 返回信息：要么返回一个基本类型（如 char, int, boolean），要么返回一个新的字符串。

3.15 字符运算

在Java中，“字符运算”通常指对char类型数据进行的数学运算，或者通过+运算符对字符进行连接的操作。

Java中的char本质上是一个无符号整数，它存储的是字符对应的Unicode码点（通常指UTF-16编码单元）。因此，它可以像整数一样参与运算。

1. 字符的算术运算

当使用+、-、*、/等算术运算符对char进行操作时，Java会自动将其提升为int类型进行计算。

  • 运算规则：实际运算的是字符对应的int数值（ASCII或Unicode码点）。
  • 结果类型：运算结果通常是int类型，需要强制转换才能变回char。

2. 字符与字符串的连接运算

当使用+运算符时，如果其中一个操作数是String类型，那么+就变成了字符串连接运算符。

  • 规则：此时，Java会将另一个操作数（包括char）转换为字符串，然后拼接在一起。

3. 转义字符

转义序列 含义
\n 换行
\t 制表符
\\ 反斜杠本身
\' 单引号（在字符字面量中使用，如 '\''）
\" 双引号（在字符串中使用）
\uXXXX Unicode转义，XXXX是4位十六进制数。这是Java语言规范的一部分，甚至在编译前就会被解析。

总结

Java中的字符运算主要围绕两点：

  1. 当作整数运算：利用字符的底层数字码进行计算（如大小写转换、循环遍历字母）。
  2. 当作字符串拼接：当与字符串相遇时，+号变为连接符，将字符转为字符串。

3.17 条件表达式（三元运算符）

在Java中，条件表达式是一种根据布尔条件选择不同值的简洁语法，通常被称为三元运算符。

基本语法

执行逻辑：

  • 如果布尔表达式为 true，整个表达式的值为 值1
  • 如果布尔表达式为 false，整个表达式的值为 值2

注意事项

  • 确保类型一致性：值1 和 值2 的类型应该兼容
  • 可读性：简单的条件判断使用三元运算符，复杂的逻辑建议使用 if-else
