3.1 列表的抽象数据类型（ADT）

列表抽象数据类型（List ADT） 是一种按照线性顺序组织数据元素的抽象数据类型。它强调“逻辑上的线性关系”，而隐藏了具体的物理存储结构（如数组或链表）。

3.1.1 核心特征

  • 线性结构：除第一个元素外，每个元素都有唯一的前驱；除最后一个元素外，每个元素都有唯一的后继。
  • 有序性：元素的位置由插入顺序或索引决定（区别于集合的无序性）。
  • 允许重复：与数学中的“集合”不同，列表允许存储重复的元素。
  • 动态性：大小可以动态变化（在抽象定义层面，不限制容量）。

3.1.2 常见操作

插入操作

操作 描述 示例
add(element) 在列表末尾添加元素 list.add(10) → [..., 10]
insert(index, element) 在指定位置插入元素 list.insert(2, 99) → 索引 2 处插入 99
addAll(collection) 批量添加多个元素 list.addAll([1,2,3])

删除操作

操作 描述 示例
remove(index) 删除指定索引位置的元素 list.remove(2) → 删除第 3 个元素
removeElement(element) 删除第一个匹配的元素值 list.removeElement(5) → 删除值为 5 的元素
clear() 清空所有元素 list.clear() → []

访问与修改

操作 描述 示例
get(index) 获取指定索引的元素 int x = list.get(3)
set(index, element) 替换指定索引的元素 list.set(1, 100) → 将索引 1 改为 100
indexOf(element) 查找元素第一次出现的索引 int pos = list.indexOf(42)
lastIndexOf(element) 查找元素最后一次出现的索引 int pos = list.lastIndexOf(42)

查询与状态

操作 描述 示例
size() 返回元素个数 int len = list.size()
isEmpty() 判断是否为空 if (list.isEmpty())
contains(element) 判断是否包含某元素 if (list.contains(5))
subList(from, to) 获取子列表（视图） list.subList(1, 4) → 索引 1~3

遍历操作

操作 描述 示例
iterator() 获取迭代器 for (var e : list)
forEach(consumer) 函数式遍历（Lambda） list.forEach(e -> System.out.println(e))

批量操作

操作 描述 示例
addAll(collection) 追加另一个集合 list.addAll(otherList)
removeAll(collection) 删除所有在集合中的元素 list.removeAll([1,2])
retainAll(collection) 仅保留集合中的元素 list.retainAll([1,2])

其他常见操作

3.2 单链表

单链表是一种线性数据结构，由一系列节点组成，每个节点包含数据域和指针域（指向下一个节点）。

与数组不同，单链表中的元素在内存中不连续存储，通过指针链接成链。

核心结构

  • 头指针：指向第一个节点，是访问链表的唯一入口
  • 节点：包含数据域（存储数据）和指针域（存储下一个节点的地址）
  • 尾节点：指针域指向 NULL，表示链表结束

主要操作

操作 时间复杂度 说明
头插法 O(1) 新节点插入链表头部
尾插法 O(n) 需遍历到尾部（维护尾指针可优化为O(1)）
指定位置插入 O(n) 需先遍历到目标位置
删除节点 O(n) 需找到前驱节点
查找 O(n) 顺序遍历
遍历 O(n) 访问所有节点

特点总结

优点

  • 动态内存分配，无需预先分配连续空间
  • 插入和删除操作效率高（仅需修改指针）
  • 空间利用率灵活，随用随申请

缺点

  • 不支持随机访问，只能顺序遍历
  • 需要额外存储指针，有内存开销
  • 查找效率较低，为 O(n)

与其他结构的对比

特性 单链表 顺序表（数组） 双链表
存储方式 非连续 连续 非连续
随机访问 不支持 支持 O(1) 不支持
插入/删除 O(1)* O(n) O(1)*
内存占用 数据+指针 仅数据 数据+两个指针
反向遍历 不支持 支持 支持

*注：指已知插入位置的情况下

适用场景

  • 频繁插入/删除，但很少随机访问
  • 实现栈、队列等抽象数据类型
  • LRU 缓存淘汰算法
  • 多项式运算、大数运算等动态结构需求

3.3 单链表：查询和插入

3.3.1 单链表的节点结构

  • 数据域：存储具体的数据（可以是任意类型，这里用泛型 T 表示）。
  • 指针域：存储下一个节点的引用（Java 中就是对象引用）。

3.3.2 单链表的查询

按值查找

从头部开始，依次比较每个节点的数据，直到找到匹配的值或到达链表末尾。

按索引查找

从头部开始，计数器记录当前位置，直到找到指定索引或超出链表长度。

  • 按值查找：最坏情况下需要遍历整个链表，时间复杂度为 O(n)。
  • 按索引查找：同样需要遍历到指定位置，时间复杂度为 O(n)。

3.3.3 单链表的插入

头部插入

新节点成为新的头节点，其 next 指向原来的头节点。

尾部插入

如果链表为空，新节点直接作为头节点；否则遍历到最后一个节点，将其 next 指向新节点。

指定节点后插入

已知一个节点 prevNode（不为空），将新节点插入到它后面。

指定位置插入（索引位置）

如果索引为 0，则头插；否则找到索引位置的前一个节点，然后在其后插入。

时间复杂度

  • 头插法：O(1)。
  • 尾插法：O(n)（因为需要遍历找到尾部，可以维护尾指针优化为 O(1)）。
  • 中间插入：O(n)（查找前驱节点需要遍历）。

总结

  • 单链表 由节点组成，每个节点包含数据和指向下一个节点的引用。
  • 查询 需要遍历，时间复杂度 O(n)。
  • 插入 在头部为 O(1)，在尾部或中间需要先定位，时间复杂度 O(n)。
  • Java 实现中，注意空指针处理，特别是插入和查找时对头节点的判断。

3.4 单链表：删除

在数据结构中，单链表的删除操作指的是从链表中移除一个节点。

由于单链表是单向的，每个节点只知道下一个节点的位置，因此删除操作的核心是：找到要删除节点的前一个节点，然后将其指针指向要删除节点的下一个节点。

删除头节点

  • 操作：将头指针指向原头节点的下一个节点。

  • 时间复杂度：O(1)

3.5 基于数组的列表

在数据结构中，基于数组的列表是一种使用连续内存空间来存储元素的线性表实现方式。它通常被称为顺序列表或动态数组

核心特点

特点 说明
物理存储 内存中连续的一块区域
逻辑顺序 元素按插入顺序排列
随机访问 通过索引 O(1) 时间访问任意元素
动态扩容 容量不足时自动分配更大的数组并复制

主要操作复杂度

操作 时间复杂度
访问/修改（按索引） O(1)
尾部插入/删除 O(1) 均摊
中间插入/删除 O(n)
查找元素 O(n)

扩容机制

当 size == capacity 时触发扩容：

  1. 创建新数组（通常为原容量的 1.5 倍或 2 倍）
  2. 复制所有元素到新数组
  3. 释放原数组

优缺点

优点 缺点
✅ 内存连续，CPU 缓存友好 ❌ 插入/删除（非尾部）需要移动元素
✅ 随机访问速度极快 ❌ 扩容时有复制开销
✅ 实现简单 ❌ 可能造成内存浪费（预留容量未用）

与链表的对比

特性 基于数组的列表 链表
随机访问 O(1) ✅ O(n)
中间插入/删除 O(n) O(1)（已知位置）
内存开销 可能预留空间 每个节点多存指针
缓存局部性 好 差

适用场景：读多写少、频繁按索引访问、尾部增删为主的情况。
