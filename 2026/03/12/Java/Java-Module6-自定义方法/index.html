自定义方法是指程序员根据需求自己定义的方法（也称为函数），用来执行特定功能的代码块。这是Java编程中最基础也最重要的概念之一。

  • 参数列表：可选的输入参数，格式为类型 参数名

6.11 变量/方法定义的作用域

在Java中，作用域（Scope） 定义了变量和方法的可见性和生命周期。理解作用域是编写正确、高效Java代码的基础。

6.11.1 变量作用域

根据变量声明的位置不同，变量主要分为三类：成员变量（包括类变量和实例变量） 和 局部变量。

A. 局部变量

  • 定义：在方法、构造方法或代码块内部声明的变量。
  • 作用域：从声明的位置开始，到包含它的代码块（花括号 {}）结束为止。在该代码块之外无法访问。
  • 生命周期：当方法被调用时创建，方法执行完毕后销毁（释放内存）。

B. 成员变量

定义在类里面、方法外面。

  1. 实例变量 （Instance Variables）
    • 定义：不在方法内，且没有使用 static 关键字修饰的变量。
    • 作用域：在整个类内部都有效（非静态方法中可以直接使用）。它的可见性还受到访问修饰符（public， protected， private）的影响。
    • 生命周期：随着对象的创建而创建，随着对象被垃圾回收而销毁。
  2. 类变量 （静态变量， Static Variables）
    • 定义：使用 static 关键字修饰的变量。
    • 作用域：在整个类内部都有效（包括静态方法和非静态方法）。同样受访问修饰符控制。
    • 生命周期：随着类的加载而创建，随着类的卸载（通常直到程序结束）而销毁。它是所有实例共享的。

6.11.2 方法作用域

方法的作用域主要指的是方法的可见性（谁能调用这个方法）以及方法内部变量的作用域。

A. 方法的可见性（由访问修饰符决定）

方法的作用域范围主要由访问修饰符控制，这与成员变量的规则一致：

  • public：作用域最大。任何类、任何包都可以访问。
  • protected：作用域限于同一个包 或者 不同包的子类。
  • 默认 （包私有，无修饰符）：作用域仅限于同一个包内。
  • private：作用域仅限于同一个类内。外部无法访问。

B. 方法参数的局部作用域

方法签名中定义的参数（形参）也是局部变量，它们的作用域就是整个方法体。

6.11.3 作用域遮蔽 （Shadowing）

当局部变量和成员变量同名时，局部变量会遮蔽成员变量。此时在该方法内直接使用变量名访问的是局部变量。

如果需要访问成员变量，必须使用 this 关键字（对于实例变量）或类名（对于静态变量）。

总结

类型 关键字/位置 作用域 生命周期
局部变量 方法/代码块内 所属的 {} 代码块 方法调用期间
实例变量 类内，无 static 整个类（受访问修饰符限制） 对象存活期间
类变量 类内，有 static 整个类（受访问修饰符限制） 类存活期间（通常程序运行期间）
方法参数 方法签名中 整个方法体 方法调用期间
方法本身 类内 由访问修饰符决定可见范围 类存活期间（静态方法）或对象存活期间（实例方法）

6.12 方法名重载

方法重载（Overloading）是指在同一个类中，允许存在多个同名方法，但参数列表不同的现象。这是Java实现多态性的一种方式。

重载规则

  1. 方法名相同
  2. 参数列表不同（满足以下至少一项）：
    • 参数个数不同
    • 参数类型不同
    • 参数顺序不同
  3. 与返回值类型无关（仅靠返回值不同不能构成重载）
  4. 与访问修饰符无关

6.15 完美尺寸数组

在Java中，“完美尺寸数组”通常指的是数组的长度（元素个数）恰好等于其分配的内存大小，即没有浪费内存空间，数组的容量被完全利用。

6.15.1 数组的“大小”定义

在Java中，数组是一个对象，它有两个关键属性：

  • length：这是数组的固有属性，表示数组可以存储的元素个数。
  • 内存占用：数组对象在堆内存中占据一块连续的空间，这块空间的大小由 length 和元素类型决定。

结论： 在Java里，一个数组一旦被创建（通过 new 关键字），它的长度就是固定的。此时，它拥有的元素个数（length）就等于它分配的内存所能容纳的元素个数。

6.20 从方法中构造返回数组

在Java中，由于方法只能返回一个值（一个引用），而数组可以包含多个数据，因此返回数组是方法返回多个同类型数据的标准方式。

核心概念

  1. 方法定义：方法的返回类型需要声明为数组类型（例如 int[]、String[]）。
  2. 构造数组：在方法内部使用 new 关键字创建数组并赋值。
  3. 返回数组：使用 return 关键字返回数组的引用。

返回数组的引用（内存分析）

在Java中，数组是对象。当方法返回数组时，实际上返回的是指向堆内存中该数组对象的引用。

  • 方法内部：int[] result = new int[n]; 在堆上创建了数组对象，result 是栈上的局部变量，保存了该对象的地址。
  • 返回时：return result; 将这个地址值传回给调用者。
  • 调用方：int[] fibonacci = getFibonacciArray(10); 将接收到的地址赋值给 fibonacci 变量。现在 fibonacci 和方法内部的 result 指向堆中的同一个数组对象

返回空数组 vs 返回 null

当方法没有数据可返回时（例如根据条件查询不到结果），有两种常见的处理方式：

  • 返回 null：表示没有数组对象。

缺点：调用者必须进行 null 检查，否则容易引发 NullPointerException。

  • 返回空数组：返回一个长度为0的数组对象。

优点：调用者可以安全地使用 for-each 循环（循环不会执行），无需担心空指针异常。这是一种推荐的做法。

6.22 Java方法文档

在Java中，方法文档（通常称为 Javadoc）是一种用于描述方法功能、参数、返回值以及可能抛出异常的注释。

它不仅是为了给阅读代码的人看，更重要的是，可以通过 Javadoc 工具自动生成一份漂亮的 API 说明文档（也就是像官方文档那样的网页）。

基本语法结构

方法文档必须紧贴在方法声明之前，以 /** 开头，以 */ 结束，中间通常使用 @ 符号来添加特定的标签。

标准模板

常用的 Javadoc 标签

标签 作用 适用场景
@param 描述方法的参数 几乎每个有参数的方法
@return 描述方法的返回值 非 void 的方法
@throws 描述方法可能抛出的异常 方法声明了 throws 时
@see 指向相关的类或方法（参考链接） 需要建立关联时
@since 表示该方法从哪个版本开始引入 版本管理
@deprecated 表示该方法已过时，建议不要再使用 标记废弃方法，并说明替代方案
