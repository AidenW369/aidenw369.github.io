输入/输出

11.1 标准输入输出文件指针

11.1.1 C 语言中的 stdout 和 stdin 文件指针

在 C 语言中，stdin、stdout 和 stderr 是三个标准的文件指针（类型为 FILE *），它们定义在 <stdio.h> 头文件中。当程序启动时，这三个流会被自动打开，不需要你手动调用 fopen。

三个标准流

名称 全称 默认指向 用途
stdin standard input 键盘 标准输入
stdout standard output 屏幕（终端） 标准输出
stderr standard error 屏幕（终端） 标准错误输出

11.1.2 stdin（标准输入）

stdin 是程序读取输入数据的来源，默认连接到键盘。

像 scanf、getchar、gets 这类函数，本质上都是从 stdin 读取数据。

11.1.3 stdout（标准输出）

stdout 是程序输出正常结果的目标，默认连接到屏幕。它通常是带缓冲的（行缓冲或全缓冲）。

printf、putchar、puts 实际上都是把数据写入 stdout。

一个关键区别：stdout vs stderr

  • stdout 用于程序的正常输出，通常带缓冲（数据可能先存在缓冲区，等满了或遇到换行才真正显示）。
  • stderr 用于错误信息，通常不带缓冲（立即输出），这样即使程序崩溃，错误信息也不会丢失。

11.1.4 重定向（Redirection）

这三个流的强大之处在于它们可以被重定向。在命令行中：

11.2 输出格式化

C语言的 Output formatting(输出格式化)指的是控制数据如何显示到屏幕或文件中的方式。它主要通过 printf 系列函数和**格式说明符(format specifier)**来实现。

核心概念

格式化输出的核心是 printf 函数,它的工作方式是:在字符串中放入以 % 开头的"占位符",然后把后面的参数按指定格式填进去。

这里的 %d 就是格式说明符,表示"在这个位置放一个十进制整数"。

常用格式说明符

说明符 含义 示例
%d / %i 十进制整数 printf("%d", 42) → 42
%f 浮点数(小数) printf("%f", 3.14) → 3.140000
%c 单个字符 printf("%c", 'A') → A
%s 字符串 printf("%s", "hi") → hi
%x 十六进制 printf("%x", 255) → ff
%o 八进制 printf("%o", 8) → 10
%e 科学计数法 printf("%e", 1234.0) → 1.234000e+03
%% 输出百分号本身 printf("%%") → %

精细控制(宽度、精度、对齐)

格式说明符还可以加上修饰来控制具体样式,完整结构是:%[标志][宽度][.精度][长度]类型

11.3 输入解析

Input parsing（输入解析） 指的是程序读取输入数据，并把它从原始的文本/字节流，转换成程序可以使用的、有意义的数据结构（如整数、浮点数、字符串、字段等）的过程。

简单说就是：把"一堆字符" → 解析成"有用的数据"。

11.3.1 为什么需要输入解析？

程序从键盘、文件或网络读到的数据，本质上都是 字符序列（文本）。例如用户输入：

这只是一串字符 '2','5',' ','3',...。程序需要把它解析成：

  • 整数 25
  • 浮点数 3.14
  • 字符串 "hello"

这个转换过程就是 input parsing。

注意

  1. 检查返回值：scanf/sscanf 返回成功解析的项数，一定要检查它来判断解析是否成功。
  2. 缓冲区溢出：%s 要限定宽度（如 %49s），否则可能溢出。
  3. scanf 残留换行符：%d 后接 %c 容易读到残留的 \n，这是新手常见 bug。
  4. 优先用 strtol 而非 atoi：因为 atoi 无法区分"解析失败"和"输入就是0"。

11.4 文件输入和输出

文件输入输出指的是程序与磁盘文件之间进行数据读写的操作。它让程序可以把数据永久保存到文件中（输出），或者从文件中读取已有的数据（输入），而不像变量那样在程序结束后就丢失。

核心概念：文件指针

在C语言中，对文件的所有操作都通过一个特殊的指针来完成，它的类型是 FILE *：

这个指针指向一个包含文件信息的结构体（位置、状态等），相关定义都在 <stdio.h> 头文件中。

补充要点

  • EOF：读到文件末尾时，读取函数会返回 EOF（或 fgets 返回 NULL），常用来作为循环结束的判断条件。
  • 文本模式 vs 二进制模式：文本模式会对换行符做转换（尤其在 Windows 上），二进制模式则原样读写，适合图片、结构体等数据。
  • 标准流：stdin（标准输入）、stdout（标准输出）、stderr（标准错误）本身就是预先打开的 FILE *，所以 printf 其实等价于 fprintf(stdout, ...)。
