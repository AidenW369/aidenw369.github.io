9.2 递归函数

递归函数是C语言中一个函数调用自身的编程技术。它将复杂问题分解为更小的同类子问题，直到达到一个"基本情况"（base case）为止。

递归函数的两个核心要素

基本情况（Base Case）：终止递归的条件，防止无限循环。

递归情况（Recursive Case）：函数调用自身，每次调用使问题规模缩小。

经典示例：阶乘

另一个示例：斐波那契数列

递归的优缺点

优点 缺点
代码简洁，逻辑清晰 每次调用消耗栈内存
非常适合树、图等结构 深度过大可能导致栈溢出
分治算法的自然表达 可能存在重复计算（如斐波那契）

注意事项

  • 必须有终止条件，否则会无限递归导致程序崩溃。
  • 递归深度过大时，考虑改用**迭代（循环）*或*尾递归优化。
  • 对于斐波那契等重复子问题，可以用动态规划提升效率。

9.3 递归算法：搜索

递归搜索算法是指函数调用自身来解决问题的算法。它将一个大问题分解为若干个相同结构的小问题，直到达到**基本情况（base case）**为止。

核心思想

每个递归函数包含两部分：

  1. 基本情况（Base Case）：递归终止的条件，防止无限循环。
  2. 递归情况（Recursive Case）：调用自身，缩小问题规模。

9.6 递归数学函数

递归数学函数是指函数调用自身来解决问题的编程方式。在C语言中，递归函数通常对应数学上的递推定义。

基本概念

一个递归函数由两部分组成：

  1. 基础情况（Base Case）：终止递归的条件，防止无限循环。
  2. 递归情况（Recursive Case）：函数调用自身，每次向基础情况靠近。

9.6.1 经典数学递归示例

1. 阶乘（Factorial）

数学定义：

  • 0! = 1
  • n! = n × (n-1)!

2. 斐波那契数列（Fibonacci）

数学定义：

  • F(0) = 0, F(1) = 1
  • F(n) = F(n-1) + F(n-2)

3. 幂运算（Power）

数学定义：

  • x⁰ = 1
  • xⁿ = x × xⁿ⁻¹

4. 最大公约数（GCD，辗转相除法）

数学定义（欧几里得算法）：

  • gcd(a, 0) = a
  • gcd(a, b) = gcd(b, a % b)

注意事项

注意点 说明
必须有基础情况 否则会无限递归，导致栈溢出
每次递归需向基础情况靠近 否则永远无法终止
性能问题 如斐波那契，存在大量重复计算，可用记忆化或迭代优化
栈空间有限 递归深度过大会导致 Stack Overflow

关键要点总结

概念 说明
