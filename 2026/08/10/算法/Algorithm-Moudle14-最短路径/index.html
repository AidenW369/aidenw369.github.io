最短路径

14.1 最短路径导论

14.1.1 问题背景：路网（road network）

建模方式：把一组道路的连接结构抽象成图

  • 顶点：路口、断头路（dead end）
  • 边：两个顶点之间的路段

核心需求：找出两个顶点之间的最短路径，典型场景是 GPS 导航中最小化驾驶距离。

关键观察：在路网中，“边数少"≠"路径短”。不同路段的长短、通行时间差异很大，因此需要给边赋予长度（可表示驾驶距离或驾驶时间）。

⚠️ 路径长度 = 路径上所有边长度之和，而不是边的数量。
这正是本章与"无权图 BFS 最短路"的分界点。

14.1.2 加权图（weighted graph）

概念 说明
定义 每条边 e 都带一个数值标签 w(e) 的图
w(e) 称为边 e 的权重（weight）
取值范围 整数、有理数、实数均可
语义 距离、连接成本、亲和度（affinity）等

本章目标：求解加权图上的最短路径问题，例如路网中的最优驾驶路线。

14.2 单源最短路径（Single-Source Shortest Paths）笔记

14.2.1 基本概念

**路径的长度（length / weight）**设 G 为加权图，路径 P 的长度就是其所有边权之和。若 P 由边 e0,e1,…,ek−1 组成，则

​ w(P)=∑i=0k−1w(ei)

距离（distance）顶点 u 到 v 的距离记作 d(u,v) ，定义为 u→v 所有路径中长度最小者的长度，该路径称为最短路径（shortest path）。

约定：若 u 到 v 根本不存在路径，则 d(u,v)=+∞ 。

14.2.2 负权边与负权环的问题

当图中存在负权边时，距离的定义需要额外小心。

核心问题：负权环（negative-weight cycle）
若图中存在总权重为负的环，则距离可能没有定义。

书中的机票例子：

元素 含义
顶点 城市（如 JFK、ORD）
边权 从一个城市到另一个城市的花费
负权边 有人倒贴钱让你走这条路（如 JFK → ORD 花费为负）

如果 JFK → ORD 和 ORD → JFK 都是负权，就形成了负权环。此时任何人都能构造这样的路径：先到 JFK，在 JFK ↔ ORD 之间来回绕任意多圈，再前往目的地 vv v —— 每绕一圈总花费就更低一次，可以得到任意小的负值路径（顺便发一笔财）。

结论： 距离不可能是任意小的负数，因此当用边权表示距离时，必须保证图中不存在负权环。

14.2.3 问题分类与对应算法

1. 单源最短路径问题

给定加权图 G 和源点 s，求 s 到图中每一个其他顶点的最短路径（把边权视作距离）。

  • 典型应用：s 是消防站等重要位置，需预先算出到所有顶点 v 的距离 d(s,v) 及最优路径。
  • 特例回顾：当所有边权都为 1 时，即为 BFS 遍历（13.4 节）解决的问题。以下算法是带权的一般化推广。
算法 适用条件 设计范式
Dijkstra 所有边权非负（w(e)≥0），因而可提前保证无负权环 贪心法（greedy method）
Bellman-Ford 允许负权边 动态规划（非贪心）

2. DAG 上的最短路径

针对**有向无环图（DAG）**这一特殊情形，存在更高效的专用算法（后续章节讨论）。

3. 全源最短路径问题（All-Pairs Shortest Path）

目标：预计算图中每一对顶点之间的最短路距离。

  • 朴素做法：以每个顶点为源点，跑 nn n 次单源最短路径算法。
  • 但根据图的具体参数（如稠密/稀疏），存在更高效的方法。

14.3 Dijkstra 算法

14.3.1 适用前提与核心思想

前提：图 G 的所有边权非负，即 w(e)≥0。由此可知图中不存在负权回路。这个前提是算法正确性的关键。

设计范式：贪心法（greedy method）——每一轮从当前可选项中挑"最好"的那个。

主要思路：把它看作"带权版的广度优先搜索"。

  • 从源点 s 出发，逐步扩张一个顶点"云" C；
  • 顶点按照到 s 的距离由小到大依次进入云；
  • 每一轮选取云外离 s 最近的那个顶点加入；
  • 当云外没有顶点时终止，此时得到s 到所有顶点的最短路长度。

bootstrapping（自举）技巧：贪心决策需要"最短距离"，但我们此刻还不知道真实距离——看似循环论证。解决办法是先维护一个距离的近似值 D[v]，随算法推进不断改进，最终收敛到真实距离。

14.3.2 标签与边松弛（Edge Relaxation）

标签定义：D[v] 表示"到目前为止"发现的 s→v 最短路径长度（即真实距离的上界估计）。

初始化：

​ D[s]=0,D[v]=∞ (v≠s),C=∅

每轮迭代：

  1. 选出云外 D 值最小的顶点 u（实践中用优先队列实现），把 u 拉进 C；第一轮拉进来的必然是 s；
  2. 对 u 的所有云外邻居 v 更新标签——因为可能出现"经由 u 到 v"的更优路线。

松弛操作（取旧估计，检查能否更接近真值）：

​ if D[u]+w(u,v)<D[v] then D[v]=D[u]+w(u,v)

14.3.3 伪代码

注意：Q 里存的正好是云外的顶点（Q=V∖C），所以"v 在 Q 中"等价于"v 不在云里"。

14.3.4 正确性：为什么它是对的

关键性质：顶点 u 被拉进 C 的那一刻，D[u] 就已经等于真实的最短距离，不会再被后续松弛改变。因此算法终止时所有 D 值都正确。

引理

在 Dijkstra 算法中，每当顶点 v 被拉进云时，D[v]=d(s,v)（真实最短路长度）。

证明分两步：

**第一步：任何时刻恒有 D[v]≥d(s,v)。**对算法步骤做归纳，不变式是：若 D[v]≠∞，则一定存在一条实际的 s→v 路径，其代价正好是 D[v]。

  • 初始：D[s]=0=d(s,s)，其余为 ∞；
  • D[v] 只在松弛时下降，此时 D[v]=D[u]+w(u,v)。由归纳假设存在代价为 D[u] 的 s→u 路径，接上边 (u,v) 就得到代价为 D[v]的 s→v 路径。

既然 D[v] 总对应一条真实路径，它就不可能小于最短路。

第二步：反证法。假设存在顶点 D[v]≠d(s,v)，即 d(s,v)<D[v]≤∞。取第一个被错误地取出并加入云的顶点 z，满足 D[z]>d(s,z)。

由 d(s,z)<∞，存在最短路 P:s⇝z。在 z 被选中的那一刻：

  • 令 y 为 P 上（从 s 走向 z）第一个不在 C 中的顶点（可能 y=z）；
  • 令 x为 P 上 y 的前驱（可能 x=s），由 y 的选法可知 x∈C。

推导链条：

  1. 因为 z 是第一个出错的顶点，而 x 先于 z 入云，所以 D[x]=d(s,x)。
  2. x 入云时松弛过边 (x,y)，故
    D[y]≤D[x]+w(x,y)=d(s,x)+w(x,y)
  3. 又 y 是最短路上 x 的后继，上式右端正是 d(s,y)；结合第一步的 D[y]≥d(s,y)，得
    $ D[y]=d(s,y)$
  4. 此刻算法选的是 zz z 而不是 yy y（zz z 的键最小），故
    D[z]≤D[y]
  5. 最短路的子路径也是最短路，故 d(s,y)+d(y,z)=d(s,z)；
  6. 因为无负权边，d(y,z)≥0。

合起来：

​ D[z]≤D[y]=d(s,y)≤d(s,y)+d(y,z)=d(s,z)

这与$ D[z]>d(s,z)$ 矛盾，故不存在这样的 z。

记住第 6 步：整个证明唯一用到"非负权"的地方就在这里。这正是 Dijkstra 无法处理负权边的根源。

13.4.5 运行时间分析

记 n=∣V∣，m=∣E∣，假设边权的加法与比较为 O(1)。图用邻接表/邻接映射存储。

与优先队列无关的部分

  • 内层 for 循环（遍历 uu u 的邻居）的总迭代次数为 $\sum_{u \in V_G} \mathrm{outdeg}(u) = O(m) $；
  • 外层 while 循环执行 O(n) 次（每轮恰有一个顶点入云）。

实现一：堆（heap）

操作 单次代价 总代价
建队（逐个插入） O(log⁡n) O(nlog⁡n)
建队（自底向上建堆） — O(n)
removeMin O(log⁡n) O(nlog⁡n)
改键（每次松弛一次） O(log⁡n) O(mlog⁡n)

标准堆不支持删除任意元素，需借助 **locator（定位器）**模式：为每个顶点维护一个指针， O(1) 定位它在堆中的结点，再做上滤/下滤， O(log⁡n) )。

总时间：

​ ∑v∈G(1+deg⁡(v))log⁡n=O((n+m)log⁡n)

连通图下 n=O(m)，可写成 $O(m \log n) $。

实现二：无序双向链表

  • removeMin 需扫描全表：O(n)，共 O(n2) ；
  • 改键借助定位器可 O(1)，共O(m)。

总时间 O(n2+m) ；因 G 是简单图（ m=O(n2) ），简化为 O(n2) 。

定理

对含 n 个顶点、m 条非负权边的简单加权图 G 与顶点 v，Dijkstra 算法可在 $O(m \log n) $ 时间或 O(n2) 时间内算出 v 到其余所有顶点的距离。

两种实现如何取舍

两者编码难度、常数因子都差不多，只看渐进最坏情况：

情形 更优选择
边稀疏， m<n2/log⁡n 堆实现 O((n+m)log⁡n)
边稠密， m>n2/log⁡n 无序序列实现 O(n2)

进阶：**斐波那契堆（Fibonacci heap）**可把时间降到 $O(m + n\log n) $，不劣于上述任一实现。

13.4.6 重建最短路径树

Algorithm 只给出距离 D[v]，没有给出具体路径。但所有从 s 出发的最短路径可以紧凑地表示为一棵最短路径树（shortest-path tree）。

为什么是树：若 s→v 的最短路经过中间点 u，那么它的前半段必然是 s→u 的最短路（最优子结构），因此每个 v≠s 只需记录一个父节点。

判据：若 u 是某条 s→v 最短路上 v 的紧前驱，则

D[v]=D[u]+w(u,v)

反之，若该等式成立，则"s→u 的最短路 + 边 (u,v)"也是一条 s→v 的最短路。于是只需枚举每个 v 的入边，找到满足等式的 (u,v)。

时间：遍历每个顶点及其所有入边，共 O(n+m)O(n + m) O(n+m)。

14.4 Bellman-Ford 算法

14.4.1 为什么需要它

  • Dijkstra 依赖贪心策略，一旦图中有负权边就会失效（14.3 节的结论）。
  • Bellman-Ford 用于带负权边的有向加权图求单源最短路，并且能顺带检测负权环。
  • 与 Dijkstra 的共同点：都用标号 D[v] 作为 d(s,v) 的上界，反复做**松弛（relaxation）**逼近真值。
  • 关键区别：不使用贪心选点，而是"无脑"地对全部边反复松弛。

14.4.2 算法

结构上就两块：n−1 轮全边松弛 + 额外一轮用于检测负权环。

14.4.3 正确性

引入辅助概念 i-边距离 dᵢ(s,v)：从 s 到 v 的所有最多 i 条边的路径中的最短长度。

归纳命题：第 i 轮主循环结束后，对所有 v 有 D[v] ≤ dᵢ(s,v)。

  • 基础（i=0）：D[s] = 0 = d₀(s,s)；其余 D[v] = +∞ = d₀(s,v)。

  • 归纳步

    ：设第 i−1 轮后

    。最优的 i-边路径只有两种情形：

    1. dᵢ(s,v) = d_{i−1}(s,v)（第 i 条边用不上）→ 由于 D[v] 只减不增，仍成立。
    2. dᵢ(s,v) = d_{i−1}(s,u) + w(u,v) → 因为第 i 轮遍历了每一条边，边 (u,v) 一定被松弛过，故 D[v] ≤ D[u] + w(u,v) ≤ d_{i−1}(s,u) + w(u,v) = dᵢ(s,v)。

两种收尾情形：

第 n 轮还能松弛 说明
能 说明存在 dₙ(s,v) < d_{n−1}(s,v)，即"用 n 条边更短"。但图只有 n 个顶点，n 边路径必然重复某个顶点 z，即含环；而绕环反而更短（零边自距离为 0），故该环为负权环。
不能 无负权环。此时任意最短路至多 n−1 条边，于是 D[v] = d_{n−1}(s,v) = d(s,v)。

这也解释了为什么循环次数是 n−1：无负权环时最短路最多 n−1 条边；第 n 轮若仍有改进，唯一解释就是负权环。

14.4.4 复杂度

  • 主循环 n−1 轮，每轮对 m 条边各做 O(1) 松弛 → O(nm)。
  • 空间 O(n)（只需 D 数组；若要还原路径需再存前驱数组）。
  • 对比：Dijkstra 为 O((n+m) log n)，更快但不支持负权边。

14.5 有向无环图(DAG)上的最短路径 —— 笔记整理

14.5.1 核心结论

在有向无环图这一特殊情形下,单源最短路径问题可以在 O(n + m) 时间内解决,比通用的 Dijkstra 和 Bellman-Ford 都快。

算法 适用图 时间复杂度
Dijkstra 非负权 O((n+m) log n)(堆实现)
Bellman-Ford 允许负权,需 n−1 轮松弛 O(n·m)
DAGShortestPaths 无环有向图(可含负权) O(n + m)

14.5.2 关键前提:拓扑序

  • 定义:DAG 的拓扑序是顶点排列 (v1,v2,…,vn) ,使得只要 (vi,vj) 是一条边,就有 i<j (所有边都"向前"指)。
  • 拓扑序本身可在 O(n + m) 时间求出(第 13.6 节)。
  • 为什么它是关键:它给出了一个高效的边松弛顺序,保证每个顶点被处理时,其前驱都已经定型。因此本算法本质上就是 Bellman-Ford,但只需一遍松弛——前提是松弛顺序与拓扑序一致。

14.5.3 算法伪代码

要点

  • 每个顶点的出边只被检查一次,没有外层的 n−1 轮迭代(这是与 Bellman-Ford 的唯一差别)。
  • 循环只到 n−1 :拓扑序中的最后一个顶点 vn 不可能有出边,无需处理。
  • 若 D[v]=+∞ 保留到最后,说明 v 从 s 不可达(包括拓扑序中排在 s 之前的所有顶点)。

14.5.4 时间复杂度分析

假设用邻接表存储图:

  1. 求拓扑序:O(n + m)
  2. 初始化 D:O(n)
  3. 主循环:处理每个顶点花常数时间,加上与其出度成正比的时间 → 所有顶点出度之和 = m,故为 O(n + m)

总计:O(n + m)

14.5.5 正确性证明

用反证法:

假设 vi 是拓扑序中第一个 D[vi] 不等于真实距离 d(s,vi) 的顶点。

  1. 先证 vi 可达 D 的初值除 s 外都是 +∞ ,而 D 值只有在发现一条来自 s 的路径时才会被下调。所以 D[v]=+∞ ⟺ v 不可达。若 $v_i $ 不可达,则 D[vi]=+∞ 恰为正确答案,与假设矛盾。故 D[vi]<+∞ , vi 可达,存在 s→vi 的最短路径。
  2. 取倒数第二个顶点 设 vk 是某条 s→vi 最短路径上 vi 的前驱。由于 (vk,vi) 是一条边且顶点按拓扑序编号,必有 k<i 。
  3. 前驱是正确的 因为 vi 是第一个出错的顶点,而 k<i ,所以 D[vk] 正确(可能 vk=s ,此时 D[vk]=0 。
  4. 导出矛盾 算法按拓扑序处理顶点,处理 vk 时(在 vi 之前)会松弛它的每条出边,包括最短路径上的 (vk,vi) 。于是
    D[vi]≤D[vk]+w(vk,vi)=d(s,vi) 即 D[vi] 被赋为正确距离。矛盾。

结论:不存在这样的 vi ,所有 $D[v] $ 都正确。

14.6 全对最短路径（All-Pairs Shortest Paths）笔记

14.6.1 问题设定

  • 输入：带权有向图 G→ ，n 个顶点、m 条边。
  • 输出：任意顶点对 $(v_i, v_j) $ 之间的最短路径距离（矩阵D）。
  • 关键前提：允许负权边，但不允许负权环（有负环则最短路径无定义）。
  • 本节目标：给出多个 O(n3) 的算法。

14.6.2 朴素做法（作为基线对比）

方法 适用条件 复杂度 备注
对每个顶点跑 Dijkstra 无负权边 $O(n(m + n\log n)) $ 邻接表 + 斐波那契堆；稀疏图时优于本节算法，稠密图退化为 O(n3) 且实现更复杂
对每个顶点跑 Bellman-Ford 允许负权边、无负环 O(n2m) 最坏 m=Θ(n2) 时达 $O(n^4) $

结论：稀疏图重复 Dijkstra 更快；本节方法的价值在于能处理负权边，且在稠密图/邻接矩阵表示下更自然简洁。

14.6.3 方法一：动态规划（Floyd-Warshall 变体）

来源：由计算传递闭包的 Floyd-Warshall 算法推广而来。

1. 子问题定义

Di,jk = 从 vi 到 $v_j ，∗∗中间顶点只允许取自 {v_1,\dots,v_k} $** 的最短距离。

2. 初值（k=0，不允许任何中间点）

​ Di,j0={0i=jw((vi,vj))(vi,vj)∈G→+∞其他

3. 递推式（k>0k>0 k>0）

​ Di,jk=min{Di,jk−1,  Di,kk−1+Dk,jk−1}

含义：要么不经过 vk （沿用上一层结果），要么经过 vk （拆成 i→k 与 k→j 两段）。

4. 正确性直觉

不存在第三种更短的走法：

  • 若这条更短路径不含 vk → 与 $D^{k-1}_{i,j} $ 的定义矛盾；
  • 若含 vk → 与 Di,kk−1 或 Dk,jk−1 的定义矛盾。

该论证在有负权边但无负环时仍然成立。

5. 伪代码结构（Algorithm 14.6.1）

  • 三重循环，且 kk k 必须在最外层。
  • Theorem 14.6.1：无负环时该算法在 O(n3) 时间内求出所有点对最短距离。
  • 补充：书中写法逐层保留 Dk ，实现时可只用一个 n×n 矩阵原地更新（空间 O(n2) ）。

14.6.4 方法二：矩阵乘法视角

思路：把最短路问题看成矩阵问题。先得到 O(n4) 解法，再优化到 O(n3) 。特别适合邻接矩阵表示。（此处顶点编号从 0 开始：$v_0,\dots,v_{n-1} $）

14.6.5 方法三：矩阵闭包 + 分治（ O(n3) ）

14.6.6 总览与要点

算法 复杂度 负权边 关键思想
重复 Dijkstra O(n(m+nlog⁡n)) ✗ 贪心 + 优先队列
重复 Bellman-Ford O(n2m)→O(n4) ✓ 松弛
DP / Floyd-Warshall O(n3) ✓ 按"允许的中间顶点集"分层
矩阵幂 An−1 O(n4) ；快速幂 $O(n^3\log n) $ ✓ 按"边数上限"分层 + min-plus 乘法
矩阵闭包 A∗ （分治） O(n3) ✓ 分块 + 只需 2 次递归闭包

易考/易错点

  1. 三种"分层"参数的区别：DP 按中间顶点编号 k，矩阵幂按边数 k。
  2. Floyd-Warshall 中 k 必须是最外层循环。
  3. An−1 而不是 An ：最短路至多 n−1 条边（由"无环"推出）。
  4. min-plus 半环下，"加法单位元"是 +∞ ，对角线为 0。
  5. 分治闭包若写成 4 次递归调用就变成 $O(n^3\log n) $；正确写法只有 2 次。
  6. 所有方法都依赖无负权环这一前提。
