3.1 If-else分支简介

if-else 是C语言中最基本的条件分支结构,它根据某个条件是否成立来决定执行哪一段代码。

C语言中没有真正的布尔类型概念(C99之前),判断的核心规则是:条件表达式的值为 0 视为"假",非 0 视为"真"。

几个容易踩的坑

  • 不要把 ==(判断相等)写成 =(赋值)

  • 单条语句可以省略花括号,但建议始终保留

  • 注意悬空 else 问题——else 总是与最近的、未匹配的 if 配对,用花括号可以避免歧义。

3.5 使用逻辑运算符检测范围

C语言中的逻辑运算符用于对布尔表达式（真/假）进行逻辑组合或取反，运算结果只有两种：真（用整数 1 表示）或假（用整数 0 表示）。

3.5.1 C语言中的逻辑运算符

逻辑与 &&

只有当两个操作数都为真时，结果才为真，否则为假。

逻辑或 ||

只要有一个操作数为真，结果就为真；只有当两个都为假时，结果才为假。

逻辑非 !

单目运算符，对操作数取反：真变假，假变真。

3.5.2 短路求值

这是逻辑运算符很关键的特性。对于 &&，如果左侧为假，右侧就不再计算（因为结果必定为假）；对于 ||，如果左侧为真，右侧也不再计算（结果必定为真）。

非零即真

在C语言中，任何非零值都被视为真，只有 0 被视为假。所以 if (a) 等价于 if (a != 0)。

真值对照表

a b a && b a || b !a
真 真 真 真 假
真 假 假 真 假
假 真 假 真 真
假 假 假 假 真
  • 需要注意区分逻辑运算符（&&、||、!）和位运算符（&、|、~）——前者处理整体的真假逻辑，后者按二进制位逐位运算，两者用途完全不同。

3.11 Switch 语句

switch 语句是一种多分支选择结构，用于根据一个表达式的值，从多个代码块中选择一个执行。它是 if-else if 链的一种更清晰的替代方式。

基本语法

关键组成部分

关键字 说明
switch 后面跟一个整型或字符型表达式
case 每个分支的入口，匹配一个常量值
break 跳出 switch，防止"贯穿"到下一个 case
default 可选，当所有 case 都不匹配时执行

注意事项

  • break 很重要：如果省略 break，程序会继续执行下一个 case（称为"贯穿" fall-through）。

  • 只支持整型/字符型：switch 的表达式必须是整数类型（int, char 等），不能用浮点数或字符串。

  • default 是可选的：但建议加上，用于处理意外情况。

  • 多个 case 共用一段代码：

switch vs if-else

  • 当判断条件是一个变量与多个固定值比较时，switch 更清晰易读。
  • 当条件是范围判断（如 x > 10）时，应使用 if-else。

3.12 布尔数据类型

3.12.1 C语言中的布尔类型演变

1. 早期C语言（C89/C90）

早期C语言没有内置的布尔类型。通常用 int 来代替：

  • 0 表示 假（false）
  • 非零值（通常是 1）表示 真（true）

2. C99 引入 _Bool

C99 标准正式引入了内置布尔类型 _Bool：

  • 只能存储 0 或 1
  • 赋任何非零值都会自动转换为 1

3. <stdbool.h> 头文件

C99 同时提供了 <stdbool.h> 头文件，定义了更易读的宏：

宏名 实际值
bool _Bool
true 1
false 0

4. C23 的改进

C23 标准将 bool、true、false 升级为正式关键字，不再需要包含头文件。

总结建议

  • 使用 C99 或更高标准时，推荐引入 <stdbool.h> 并使用 bool / true / false，代码可读性更好。
  • 如需兼容旧代码，可以用 int 配合 0/1 来表示布尔值。

3.13 字符串比较

在C语言中，字符串比较是指比较两个字符串的内容是否相同，或判断它们的字典序大小关系。

核心要点

C语言中的字符串本质上是字符数组，以 \0（空字符）结尾。因此，不能直接用 == 来比较两个字符串，因为 == 比较的是指针地址，而不是内容。

3.13.1 标准库函数：strcmp

最常用的方式是使用 <string.h> 中的 strcmp 函数：

返回值 含义
0 两个字符串相等
< 0 s1 字典序小于 s2
> 0 s1 字典序大于 s2

其他相关函数

函数 说明

strncasecmp(s1, s2, n) 忽略大小写，只比较前 n 个字符

常见错误：用 == 比较字符串

strcmp 的工作原理

strcmp 逐字符比较两个字符串，直到：

  1. 找到不同的字符 → 返回它们的 ASCII 差值
  2. 同时到达 \0 → 返回 0（相等）

3.18 短路评估

短路评估（Short-circuit Evaluation）是C语言中逻辑运算符 && 和 || 的一种求值机制：当表达式的结果已经可以确定时，停止继续求值后面的操作数。

3.18.1 &&（逻辑与）的短路

只要左边的操作数为 假（0），整个表达式必然为假，右边不会被执行。

3.18.2 ||（逻辑或）的短路

只要左边的操作数为 真（非0），整个表达式必然为真，右边不会被执行。

3.18.3 短路的常见用途

1. 防止空指针解引用

2. 提高性能

将代价低或最可能确定结果的条件放在左边，避免不必要的计算。

3. 副作用控制

注意事项

  • 不要依赖短路的副作用来改变程序状态，这会使代码难以阅读和维护。
  • 短路评估只适用于 && 和 ||，位运算符 & 和 | 不具备短路特性，两边都会被求值。
  • && 左边为假则停，|| 左边为真则停。
