5.2 数组

数组是C语言中一种基本的数据结构，用于在连续的内存空间中存储多个相同类型的元素。

基本概念

  • 定义：数组是一组具有相同数据类型的变量的集合，通过一个统一的名称和下标（索引）来访问。
  • 下标从0开始：第一个元素的下标是 0，第二个是 1，以此类推。
  • 内存连续：数组的所有元素在内存中是连续存储的。

5.8 反转数组

反转数组（Reverse Array）是将数组中的元素顺序颠倒，即第一个元素变成最后一个，最后一个变成第一个，以此类推。

5.10 字符数组和C字符串

基本概念

在C语言中，字符串并不是一种内置的数据类型，而是通过**字符数组（char array）*来表示的。C字符串本质上就是一个以*空字符（null terminator）'\0' 结尾的字符数组。

声明与初始化

空字符 '\0' 的重要性

'\0' 是C字符串的终止标志，值为 0。没有它，程序就不知道字符串在哪里结束，会导致未定义行为（读取垃圾数据）。

常用操作（需引入 <string.h>）

strcmp(s1, s2) 比较字符串（返回0表示相等） strcmp(a, b)
strchr(s, c) 查找字符 strchr(s, 'e')

字符数组 vs 字符指针

常见注意事项

  1. 数组大小要比字符串长度多 1，留给 '\0'。
  2. 不能用 == 比较两个C字符串，要用 strcmp()。
  3. 不能用 = 直接赋值（数组名是常量指针），要用 strcpy()。
  4. 注意缓冲区溢出：写入数据不要超过数组大小。

四、注意事项

5.13 数组和字符串存储

5.13.1 数组（Array）

数组是在连续内存空间中存储相同类型元素的集合。

声明与初始化：

内存布局：

  • 每个元素占用相同大小的内存（如 int 占 4 字节）
  • 数组名本身是指向第一个元素的指针
  • 通过 arr[i] 访问，等价于 *(arr + i)
  • 数组大小在编译时确定，存储在**栈（stack）**上（局部数组）

5.13.2 字符串（String）

C语言没有原生的字符串类型，字符串本质上是以 \0（空字符）结尾的字符数组。

两种存储方式：

1. 字符数组（存在栈上，可修改）

内存布局：

  • 共占 6 字节（含结尾的 \0）
  • 内容可以修改（str[0] = 'h' 合法）

2. 字符串指针（指向只读区，不可修改）

  • "Hello" 存储在程序的只读数据段（.rodata）
  • str 只是一个指针，指向该只读区域
  • 不可修改内容（str[0] = 'h' 会导致段错误）

关键区别对比

特性 char str[] char *str
存储位置 栈（局部）/ 数据段 指针在栈，字符串在只读区
是否可修改 ✅ 可以 ❌ 不可以
sizeof 结果 字符串长度+1 指针大小（4或8字节）
本质 数组 指针

常见注意事项

  1. 越界访问：C不做边界检查，越界会导致未定义行为
  2. 字符串长度：strlen() 返回不含 \0 的长度，sizeof 包含 \0
  3. 动态分配：用 malloc 在堆上分配字符串，记得 free
