OpenClaw的容器化部署及踩坑

Posted on 2026-05-09 Edited on 2026-05-28 In Notes

0. 容器化的优劣势

OpenClaw 简介

OpenClaw（前身为 Clawdbot、Moltbot）是 由 Peter Steinberger 创建的开源个人 AI 智能体工具，2026 年初在开发者社区爆火，基于 MIT 许可证完全免费开源。它的核心特征是 运行在你自己的 Mac、Windows 或 Linux 硬件上，能读写文件、执行 shell 命令、在沙箱中运行代码——也正因如此，它对部署环境的隔离性非常敏感。

Cisco 的 AI 安全团队曾测试过一个第三方 OpenClaw skill，发现它在用户毫无察觉的情况下进行了数据外泄和提示词注入，研究者指出 skill 仓库缺乏足够审查机制。OpenClaw 自己的维护者 Shadow 也在 Discord 上警告过，如果你不懂怎么操作命令行，这个项目对你来说太危险了，不适合安全使用。

容器化相对于本地部署的优势

  • 环境隔离，切断部分攻击面、保证本地数据安全

  • 避免污染宿主机

  • 配置和数据持久化

  • 网络与权限可控

  • 随时迁移

劣势

  • 学习成本提高

  • 调试成本提高

  • 资源开销更大

  • 不可操作Windows 桌面 GUI

4. 踩过的坑

坑1 - 开启全局代理会导致WSL的DNS失效

原因为VPN 开启后会接管 Windows 的网络接口，修改 DNS 设置，但 WSL 不能自动感知这个变化，具体为：

  • WSL 的 /etc/resolv.conf 是启动时从 Windows 自动生成的

  • VPN 连接后 Windows 网络发生变化，但 WSL 不会重新生成这个文件

  • 结果 WSL 里的 DNS 服务器地址变成了一个不可达的地址
