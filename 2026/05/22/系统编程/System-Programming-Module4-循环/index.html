4.9 break 和 continue

这两个都是 C 语言中用于控制循环流程的关键字，但作用不同：

break — 跳出循环

break 会立即终止当前所在的循环（或 switch 语句），跳到循环体之后的代码继续执行。

continue — 跳过本次迭代

continue 会跳过当前这一次循环体中剩余的代码，直接进入下一次迭代。

对比总结

break continue
作用 终止整个循环 跳过本次迭代
执行后 跳到循环之后 跳到循环下一次
适用范围 for / while / do-while / switch for / while / do-while

4.10 变量名作用域

作用域（Scope）指的是变量在程序中可以被访问的范围。C语言中主要有以下几种作用域：

1. 块作用域（Block Scope）

在 {} 花括号内声明的变量，只在该块内有效。

2. 函数作用域（Function Scope）

仅适用于 goto 语句的标签，标签在整个函数内可见。

3. 文件作用域（File Scope）

在所有函数外部声明的变量（即全局变量），从声明处到文件结尾都可访问。

4. 函数原型作用域（Function Prototype Scope）

函数声明（原型）中的参数名，作用域仅限于该原型本身，可以省略或与定义时不同。
