2.2 int变量

在C语言中，int 是一种基本的数据类型，用于声明整数变量。

int 是 “integer”（整数）的缩写，用来存储没有小数部分的数值，比如 -3、0、42 等。

核心特性

  • 本质：在内存中划出一块固定大小的空间（通常是4字节），以二进制形式存放整数。
  • 有符号：默认的 int 是有符号的（signed int），表示正数、负数和零。如果想限定非负，要用 unsigned int。
  • 大小不定：int 的具体大小取决于编译器、操作系统和CPU架构。在16位系统上是2字节，在现代32位或64位系统上通常是4字节。
  • 范围：有了大小，能表示的数值范围也就确定了（2字节的范围约是 -32,768 到 32,767，4字节的范围约是 -21亿 到 21亿）

相关的整数类型：

  • short int（较短，通常 2 字节）
  • long int（较长，通常 4 或 8 字节）
  • long long int（更长，通常 8 字节）
  • unsigned int（无符号，只存正数和零）

声明与初始化

C语言有 short int 和 long int 等变体来适配不同大小的需求：

常见用法与注意事项

  • 打印输出：使用 %d 占位符，无符号用 %u。

  • 整数运算：运算结果仍是整数，特别要注意截断。

  • 溢出问题：超出范围会发生“环绕”或未定义行为，很危险。

2.3 标识符

C语言中的标识符（Identifier）是程序员用来给各种程序元素命名的符号，比如变量、函数、数组、结构体、宏等。它本质上就是一个"名字"，让编译器和程序员能够识别和引用程序中的不同实体。

标识符的命名规则

  • 组成字符：只能由 字母（a-z， A-Z）、数字（0-9）和 下划线（_）组成。
  • 首字符限制：第一个字符不能是数字。
  • 区分大小写：Apple、apple 和 APPLE 是三个完全不同的标识符。
  • 不能是关键字：不能用C语言保留的关键字，比如 int、if、return。
  • 长度限制：C标准规定内部名至少区分前31个字符，外部名至少6个，单字符（如循环变量i）也有特定用途。现代编译器通常支持更长，但建议不要过长。

有效与无效的标识符示例

标识符示例 是否有效 说明
myVariable ✅ 有效 字母开头，标准驼峰命名
_count ✅ 有效 下划线开头，常用于系统内部变量，需谨慎使用
Data_1 ✅ 有效 字母、数字和下划线组合
2data ❌ 无效 数字不能作为开头
my-variable ❌ 无效 连字符是非法字符

常见的命名习惯

  • 见名知意：用 studentAge 而不是 sa 或 a。
  • 变量/函数：常用驼峰命名法 (studentCount) 或下划线法 (student_count)。
  • 常量/宏：通常全大写，单词间用下划线 (MAX_SIZE)。
  • 避免误导：少用 l、O 等容易和数字混淆的字母。

2.7 浮点数（double）

在 C 语言中,**双精度浮点数(double)**是一种用于表示带小数的实数的数据类型,相比单精度浮点数(float)拥有更高的精度和更大的数值范围。

基本特征

存储大小:通常占用 8 个字节(64 位),而 float 只占 4 个字节(32 位)。

精度:大约有 15-17 位有效十进制数字,远高于 float 的 6-7 位。

数值范围:大约从 ±2.23 × 10⁻³⁰⁸ 到 ±1.79 × 10³⁰⁸。

遵循标准:大多数现代编译器采用 IEEE 754 双精度浮点数标准,其内部结构为:

  • 1 位符号位
  • 11 位指数位
  • 52 位尾数位

声明与使用

与 float 的对比

特性 float(单精度) double(双精度)
字节数 4 8
有效数字 6-7 位 15-17 位
后缀 f 或 F(如 3.14f) 无需后缀(默认就是 double)
格式化输入 %f %lf

注意事项

  1. 字面量默认是 double:在 C 中,像 3.14 这样的字面量默认就是 double 类型,如果想表示 float 需要写成 3.14f。
  2. 精度有限:即使是 double 也不能精确表示所有实数,例如 0.1 + 0.2 不会严格等于 0.3,因此比较浮点数时通常用差的绝对值小于某个极小值(如 1e-9)来判断。
  3. scanf 输入差异:用 scanf 读取时,float 用 %f,double 必须用 %lf,否则会读取错误。
  4. long double:C 还提供更高精度的 long double,但其具体大小依编译器和平台而定(可能是 80 位、96 位或 128 位)。

如果对内存占用不敏感,通常推荐默认使用 double,因为它精度更高,且现代 CPU 对 double 的运算性能与 float 相差不大。

2.8 浮点数字面量的科学计数法

在 C 语言里，科学计数法（也称指数计数法）是一种用 e 或 E 表示浮点数的方式，专门用来简洁地书写非常大或非常小的数值。

核心格式是：尾数 e 指数，表示 尾数 × 10^指数。

格式规则分解

  • 尾数部分:

    • 可以是整数或小数,如 1、1.5、0.5、3.14
    • 可以带正负号,如 -2.5e3 表示 -2500

    字母 e 或 E:

    • 大小写都可以,1.5e3 和 1.5E3 等价
    • 它代表的是"×10 的几次方",不是数学常数 e(自然对数底)

    指数部分:

    • 必须是整数(不能是小数)
    • 可以带正负号,正号可省略
    • e3 等价于 e+3,表示 10³
    • e-3 表示 10⁻³

2.10 数学函数

C语言中的数学函数是标准库提供的一组用于执行常见数学运算的预定义函数，它们大多声明在头文件 <math.h> 中。使用前需要包含这个头文件：

2.10.1 常用数学函数分类

1. 基本算术函数

  • fabs(x) — 浮点数的绝对值
  • fmod(x, y) — 浮点数取余 (x除以y的余数)
  • sqrt(x) — 平方根
  • cbrt(x) — 立方根 (C99)
  • pow(x, y) — x的y次方 (x^y)
  • hypot(x, y) — 直角三角形的斜边长度，即sqrt(x² + y²)

2. 指数和对数函数

  • exp(x) — e的x次方
  • log(x) — 以e为底的自然对数
  • log10(x) — 以10为底的对数
  • log2(x) — 以2为底的对数 (C99)

3. 三角函数

  • sin(x), cos(x), tan(x) — 正弦、余弦、正切（x以弧度为单位）
  • asin(x), acos(x), atan(x) — 反正弦、反余弦、反正切
  • atan2(y, x) — 计算y/x的反正切，能正确处理象限

4. 双曲函数

  • sinh(x), cosh(x), tanh(x) — 双曲正弦、余弦、正切

5. 取整和舍入函数

  • ceil(x) — 向上取整（天花板）
  • floor(x) — 向下取整（地板）
  • round(x) — 四舍五入 (C99)
  • trunc(x) — 截断小数部分 (C99)

6. 其他函数

  • fmax(x, y) / fmin(x, y) — 返回较大/较小值 (C99)
  • fabs(x) — 浮点数绝对值
  • ldexp(x, exp) — x * 2^exp
  • frexp(x, *exp) — 将x分解为尾数和指数
  • modf(x, *intpart) — 分解整数和小数部分
  • tgamma(x) — Gamma函数 (C99)

2.11 除法和取模

2.11.1 除法运算符 /

浮点数除法

只要两个操作数中有一个是浮点数（float 或 double），执行的就是通常的数学除法，结果也是浮点数。

整数除法

如果两个操作数都是整数，C语言会执行整数除法，即结果只保留整数部分，直接截断小数（向零取整）。

特别注意：整数除法不会四舍五入，而是直接丢弃小数部分。

2.11.2 取模运算符 %

取模运算符 % 用于求两个整数相除后的余数，不能用于浮点数。

结果的符号规则

这非常重要：a % b 的结果符号总与 a（被除数）的符号相同（符合C99及以后标准）。

可以这样记忆：只要 a 是负数，结果就是负数或零。

等式关系

除法与取模的结果总是满足：
a = (a / b) * b + (a % b)

2.11.3 常见陷阱与实用技巧

误用整数除法

因为 5 和 2 都是整数，先执行了整数除法得到 2，然后才将 2 转换为 2.0 赋值。要得到正确结果，必须将至少一个操作数转为浮点数：5.0 / 2 或 (double)5 / 2。

对负数取模

不同编程语言处理负数取模的方式不同，在C语言中，结果的符号一定与被除数相同。这在编写跨语言代码时很容易混淆。

循环与奇偶判断

取模最常用的是判断奇偶和实现循环边界。

浮点数不能取模

3.14 % 2 是错误的。如果需要对浮点数求余，可以使用标准库函数 fmod（声明在 math.h 里）。

2.16 整型溢出

C语言的整型溢出（Integer Overflow）是指当一个整数运算的结果超出了该整型类型所能表示的范围时所发生的情况。

基本概念

每种整型在C语言中都有固定的存储大小和取值范围。例如在大多数现代系统上：

  • int（32位）：范围约为 -2,147,483,648 到 2,147,483,647
  • unsigned int（32位）：范围为 0 到 4,294,967,295
  • char（8位）：范围为 -128 到 127

当运算结果超出这个范围时，就发生了溢出。

有符号整型溢出

有符号整型溢出在C标准中是"未定义行为"（Undefined Behavior），这是非常重要的一点。

理论上可能"回绕"为负数（INT_MIN），但编译器可以做任何事，包括优化掉相关代码。这经常导致难以发现的bug。

无符号整型溢出

无符号整型溢出是"良定义"的，会按模 2^n 进行回绕（wrap around）。

常见溢出场景

溢出场景总结

  • 向上溢出：运算结果大于该类型的最大值。
  • 向下溢出：运算结果小于该类型的最小值。
  • 乘法溢出：两个大数相乘极易发生，结果可能绕回一个很小的数。
  • 表达式中间溢出：如 (a + b) / 2 求平均值，可能先加时就溢出。安全写法是 a + (b - a) / 2。

溢出危害

整型溢出可能导致：

  • 程序崩溃或行为异常
  • 安全漏洞：例如缓冲区分配大小计算错误，导致缓冲区溢出攻击
  • 循环条件错误导致死循环
  • 金融、科学计算的结果错误

2.18 无符号整型（Unsigned）

C语言中的 unsigned 是一个类型修饰符,用于声明无符号整数类型,即只能表示非负数(0 和正整数)的整数。

基本概念

普通的整数类型(如 int)是有符号的,可以表示正数、负数和零。而加上 unsigned 后,该变量将不再表示负数,所有位都用于表示数值大小,因此能表示的正数范围更大。

核心区别

特性 signed (默认) unsigned
数值范围 负数、0、正数 仅 0 和正数
最高位含义 符号位（1表示负） 数值位的一部分
可表示的正数上限 大约是有符号的一半 大约是相应有符号类型的两倍

常见的 unsigned 类型

为什么需要 unsigned？

  1. 扩大正数范围
    比如 unsigned int 可以表示 0 ~ 4,294,967,295，而 signed int 只能表示 -2,147,483,648 ~ 2,147,483,647。当数据不可能为负时（如计数器、数组索引、年龄），用 unsigned 能得到更大的上限。
  2. 位运算更清晰
    进行位操作、掩码、移位时，无符号类型避免了符号扩展带来的意外。
  3. 与硬件/协议匹配
    很多硬件寄存器、网络协议、文件格式里的字段本身就是无符号的，使用 unsigned 能直接映射。

注意事项

  • unsigned 和有符号数运算时,有符号数会被隐式转换为无符号数,可能导致意外结果
  • 循环中用 unsigned 做递减判断要小心,例如 for (unsigned i = n; i >= 0; i--) 会变成死循环,因为无符号数永远 ≥ 0
