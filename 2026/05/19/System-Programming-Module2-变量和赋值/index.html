2.2 int变量

在C语言中，int 是一种基本的数据类型，用于声明整数变量。

int 是 “integer”（整数）的缩写，用来存储没有小数部分的数值，比如 -3、0、42 等。

核心特性

  • 本质：在内存中划出一块固定大小的空间（通常是4字节），以二进制形式存放整数。
  • 有符号：默认的 int 是有符号的（signed int），表示正数、负数和零。如果想限定非负，要用 unsigned int。
  • 大小不定：int 的具体大小取决于编译器、操作系统和CPU架构。在16位系统上是2字节，在现代32位或64位系统上通常是4字节。
  • 范围：有了大小，能表示的数值范围也就确定了（2字节的范围约是 -32,768 到 32,767，4字节的范围约是 -21亿 到 21亿）

相关的整数类型：

  • short int（较短，通常 2 字节）
  • long int（较长，通常 4 或 8 字节）
  • long long int（更长，通常 8 字节）
  • unsigned int（无符号，只存正数和零）

声明与初始化

常见用法与注意事项

  • 打印输出：使用 %d 占位符，无符号用 %u。

  • 整数运算：运算结果仍是整数，特别要注意截断。

  • 溢出问题：超出范围会发生“环绕”或未定义行为，很危险。

2.3 标识符

C语言中的标识符（Identifier）是程序员用来给各种程序元素命名的符号，比如变量、函数、数组、结构体、宏等。它本质上就是一个”名字”，让编译器和程序员能够识别和引用程序中的不同实体。

标识符的命名规则

  • 组成字符：只能由 字母（a-z， A-Z）、数字（0-9）和 下划线（_）组成。
  • 首字符限制：第一个字符不能是数字。
  • 区分大小写：Apple、apple 和 APPLE 是三个完全不同的标识符。
  • 不能是关键字：不能用C语言保留的关键字，比如 int、if、return。
  • 长度限制：C标准规定内部名至少区分前31个字符，外部名至少6个，单字符（如循环变量i）也有特定用途。现代编译器通常支持更长，但建议不要过长。

有效与无效的标识符示例

标识符示例 是否有效 说明
myVariable ✅ 有效 字母开头，标准驼峰命名
_count ✅ 有效 下划线开头，常用于系统内部变量，需谨慎使用
Data_1 ✅ 有效 字母、数字和下划线组合
2data ❌ 无效 数字不能作为开头
my-variable ❌ 无效 连字符是非法字符
float ❌ 无效 float是C语言关键字
$amount ❌ 无效 美元符号是非法字符
姓名 依赖编译器 现代编译器可能支持Unicode，但强烈不建议这样用

常见的命名习惯

  • 见名知意：用 studentAge 而不是 sa 或 a。
  • 变量/函数：常用驼峰命名法 (studentCount) 或下划线法 (student_count)。
  • 常量/宏：通常全大写，单词间用下划线 (MAX_SIZE)。
  • 避免误导：少用 l、O 等容易和数字混淆的字母。

2.4 算数表达式

算术表达式是C语言中由操作数（变量、常量、函数返回值等）和算术运算符组成、用于进行数学计算的式子，其计算结果是一个数值。

2.4.1 算术运算符

C语言提供以下基本算术运算符：

运算符 名称 示例 说明
+ 加 a + b 求和
- 减 a - b 求差
* 乘 a * b 求积
/ 除 a / b 求商（整数相除得整数）
% 取模 a % b 求余数（仅用于整数）
++ 自增 a++、++a 变量值加 1
-- 自减 a--、--a 变量值减 1

2.4.2 运算符的优先级与结合性

优先级从高到低：

  1. () 括号
  2. ++、--（单目运算符）、正负号
  3. *、/、%
  4. +、-（双目运算符）

2.4.3 几个关键特性

整数除法会截断小数部分

取模运算 % 只能用于整数

自动类型转换

当不同类型的数据参与运算时，编译器会自动将”低精度”类型转换为”高精度”类型再计算，例如 int + double 的结果是 double。

  • 自动转换：不同类型混合运算时，窄类型自动转为宽类型（如 int 转 float）
  • 强制转换：用 (类型) 显式转换，如 (float)a / b

2.7 浮点数（double）

在 C 语言中,**双精度浮点数(double)**是一种用于表示带小数的实数的数据类型,相比单精度浮点数(float)拥有更高的精度和更大的数值范围。

基本特征

存储大小:通常占用 8 个字节(64 位),而 float 只占 4 个字节(32 位)。

精度:大约有 15-17 位有效十进制数字,远高于 float 的 6-7 位。

数值范围:大约从 ±2.23 × 10⁻³⁰⁸ 到 ±1.79 × 10³⁰⁸。

遵循标准:大多数现代编译器采用 IEEE 754 双精度浮点数标准,其内部结构为:

  • 1 位符号位
  • 11 位指数位
  • 52 位尾数位

声明与使用

与 float 的对比

特性 float(单精度) double(双精度)
字节数 4 8
有效数字 6-7 位 15-17 位
后缀 f 或 F(如 3.14f) 无需后缀(默认就是 double)
格式化输入 %f %lf

注意事项

  1. 字面量默认是 double:在 C 中,像 3.14 这样的字面量默认就是 double 类型,如果想表示 float 需要写成 3.14f。
  2. 精度有限:即使是 double 也不能精确表示所有实数,例如 0.1 + 0.2 不会严格等于 0.3,因此比较浮点数时通常用差的绝对值小于某个极小值(如 1e-9)来判断。
  3. scanf 输入差异:用 scanf 读取时,float 用 %f,double 必须用 %lf,否则会读取错误。
  4. long double:C 还提供更高精度的 long double,但其具体大小依编译器和平台而定(可能是 80 位、96 位或 128 位)。

如果对内存占用不敏感,通常推荐默认使用 double,因为它精度更高,且现代 CPU 对 double 的运算性能与 float 相差不大。

2.8 浮点数字面量的科学计数法

在 C 语言里，科学计数法（也称指数计数法）是一种用 e 或 E 表示浮点数的方式，专门用来简洁地书写非常大或非常小的数值。

核心格式是：尾数 e 指数，表示 尾数 × 10^指数。

格式规则分解

  • 尾数部分:

    • 可以是整数或小数,如 1、1.5、0.5、3.14
    • 可以带正负号,如 -2.5e3 表示 -2500

    字母 e 或 E:

    • 大小写都可以,1.5e3 和 1.5E3 等价
    • 它代表的是”×10 的几次方”,不是数学常数 e(自然对数底)

    指数部分:

    • 必须是整数(不能是小数)
    • 可以带正负号,正号可省略
    • e3 等价于 e+3,表示 10³
    • e-3 表示 10⁻³

位数计算

**大于0：**指数 = 小数点向左移动的位数，即 230000 = 2.3 * e5

  • 或 把小数点向左移动,直到只剩一位非零数字在小数点前。移动了几位,指数就是几。

**小于0：**指数 = -(小数点向右移动到第一个非零数字之后的位数)，即：0.0000567 = 5.67 * e-5

  • 或 把小数点向右移动,直到第一个非零数字的右边，移动了几位,指数就是 -几。
