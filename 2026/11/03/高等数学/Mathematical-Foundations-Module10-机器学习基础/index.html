机器学习基础

（一）机器学习任务

一、从数据中学习（Learning from Data）

机器学习的核心流程：

  • 训练（Train）：用过去的数据学习出一个函数 f。这些数据可能带有标签（labels）。
  • 预测（Predict）：把新数据输入 f，得到预测结果。
  • 例子：用大量已标注的图片训练模型，再输入一张汽车照片，模型输出 “car”。

💡 本质：机器学习就是从历史数据中找出一个从「输入」到「输出」的映射函数，并用它处理没见过的数据。

二、机器学习的四类常见任务

任务 说明 图示特征
分类 Classification 把样本分到离散的类别中 一条分界线把红点和蓝点分开
回归 Regression 预测一个连续的数值 一条直线拟合散点的趋势
聚类 Clustering 没有标签，按相似性自动分组 数据自然形成几个簇
降维 Dimensionality Reduction 把高维数据压缩到低维，便于可视化或分析 文档按主题（能源市场、法律等）分布在二维平面上

前两类（分类、回归）通常需要带标签的数据（监督学习）；后两类通常不需要标签（无监督学习）。

三、分类（Classification）

1. 二分类：垃圾邮件识别（Spam Detection）

  • 输入：一封新邮件
  • 训练数据：已经带标签的邮件，分为「主收件箱（Primary inbox）」和「垃圾邮件（Spams）」两类
  • 模型：分类器（Classifier）
  • 输出：是否为垃圾邮件（Is Spam / Not Spam）
  • 类型：✅ 二分类（Binary classification），只有两个类别

扩展：Gmail 不仅区分垃圾邮件，还会把邮件分到 Primary（主要）/ Social（社交）/ Promotions（推广） 等多个标签页，这已经属于多分类问题。

2. 多分类：人脸识别（Face Recognition）

  • 输入：一张人脸照片
  • 训练数据：大量人脸图片 + 对应的人名（Faces & Names）
  • 输出：这个人是谁（例如某位演员的名字）
  • 类型：✅ 多分类（Multi-class），类别数量大于 2

小结

二分类 多分类
类别数 2 > 2
例子 垃圾邮件 / 正常邮件 识别是哪个人

四、回归（Regression）

例子：房价预测（Housing Price）

  • 输入：一套房子的特征
  • 模型：回归器（Regressor）
  • 输出：一个具体数值，例如 Price = $0.5M

数据中的两类变量：

  • 🎯 标签 / 目标（label / target）：要预测的量 —— Price（成交价，单位 $1,000）
  • 📋 特征（features）：用来做预测的输入变量：
特征 含义
Beds 卧室数量
Baths 浴室数量
Square Feet 房屋面积（平方英尺）
Miles to Resort 距市中心度假区的距离
Miles to Base 距滑雪场山脚的距离
Acres 占地面积（英亩）
Cars 车库可停车数
Years Old 挂牌时的房龄
DoM 在市场上挂牌多少天才售出

五、回归 vs 分类（核心区别 ⭐）

回归 Regression 分类 Classification
标签性质 有序的（ordered） 类别型的（categorical）
能否比较大小 ✅ 可以 ❌ 不可以
例子 房价：$324K < $521K < $1.2M 细菌种类：Class 1、Class 2、Class 3、Class 4

关键点：

  • 回归的标签之间有大小关系，可以排序、可以比较。
  • 分类的标签只是「名字」，没有顺序。“Class 1” 和 “Class 4” 只是不同类别，不能说 Class 1 < Class 4。

六、思考题：葡萄酒质量预测

  • 特征：葡萄酒中各种化学成分的测量值
  • 目标：Outstanding（杰出）、Very good（很好）、Good（好）、Fair（一般）、Not recommended（不推荐）
  • 问题：这是回归还是分类？

分析：

  • 这些目标看起来是文字类别，但它们存在明确的高低顺序：Outstanding > Very good > Good > Fair > Not recommended。
  • 按照本课的判断标准（看标签是否有序），它更接近回归问题：可以把等级映射为数值（如 5、4、3、2、1）来预测。
  • 补充：如果把这五个等级当成互不相关的类别来做分类也能做，但会丢失「等级有高低」这一信息。这种「有序类别」的问题在学术上也叫有序回归（Ordinal Regression），介于两者之间。

🔑 判断回归还是分类，看的是标签是否有顺序，而不是标签的表现形式是数字还是文字。

七、监督学习 vs 无监督学习

四类任务按「是否需要标签」可以划分为：

任务 学习类型
分类 Classification 🔵 监督学习
回归 Regression 🔵 监督学习
聚类 Clustering 🔴 无监督学习
降维 Dimensionality Reduction 🔴 无监督学习 或 🔵 监督学习（两者都有）

定义：

  • 监督学习（Supervised Learning）：从带标签的训练数据中学习函数。
    • 分类和回归都属于监督学习。
  • 无监督学习（Unsupervised Learning）：从没有标签的数据集中做出推断。
    • 聚类属于无监督学习。

💡 区分的关键：训练数据里有没有「标准答案」（标签）。

八、聚类（Clustering）

问题的形式化定义：

  • 输入（Input）：向量 x₁, ⋯, xₙ，以及簇的数量 k（k ≪ n，即簇数远小于样本数）
  • 输出（Output）：每个样本的预测类别 y₁, ⋯, yₙ ∈ {1, 2, ⋯, k}

图示理解：一堆没有颜色（没有标签）的点，经过聚类后，算法自动把它们分成红、绿、蓝三组。

聚类和分类的区别：

分类 聚类
训练数据有无标签 有 无
类别是否事先定义 是（如「垃圾邮件」） 否，只给定类别数量 k
学习类型 监督学习 无监督学习

注意：聚类输出的 1, 2, …, k 只是组的编号，没有实际含义，也没有顺序。

九、降维（Dimensionality Reduction）

1. 基本思想

把一个很长的向量压缩成一个短得多的向量，同时尽量保留原数据中的重要信息。

2. 应用（Applications）

  • 可视化与分析：把高维数据降到 2 维或 3 维，就能画图观察。
  • 数据预处理：让下游的机器学习任务更高效或更准确。

3. 常见方法（Methods）

方法 备注
主成分分析 PCA（Principal Component Analysis） 最经典的线性降维方法
核主成分分析 Kernel PCA PCA 的非线性扩展
流形学习 Manifold Learning 假设数据分布在低维曲面上
自编码器 Autoencoder 基于神经网络的降维方法
线性判别分析 LDA（Linear Discriminant Analysis） 会用到标签，属于监督式降维

这也解释了第七节为什么说降维「既可以是无监督，也可以是监督」：PCA 等方法不需要标签，而 LDA 需要标签。

4. 例子：自编码器处理手写数字

  • 数据：6 万张手写数字图片，每张大小 28 × 28（即每张图是 784 维的向量）
  • 做法：用自编码器把每张图压缩到 2 维，然后画在平面上
  • 结果：相同的数字（0～9）自然聚在一起，形成 10 个比较清晰的簇
  • 启示：降维后的低维表示依然保留了区分不同数字的关键信息，因此也很适合用于可视化

十、更多机器学习任务

除了前面讲过的四类基本任务，还有：

任务 说明 例子
排序 Ranking 按相关性给结果排出先后顺序 搜索引擎返回的结果列表
推荐 Recommendation 根据用户偏好推荐内容或商品 Netflix、Amazon、MovieLens、Last.fm 等
强化学习 Reinforcement Learning 通过与环境交互、根据奖励不断改进策略 AlphaGo 对战李世石（围棋）

十一、任务、方法与算法的区别 ⭐

学习机器学习时要分清三个层次：

层次 回答的问题 例子
任务（Tasks / Problems） 要解决什么问题？ 回归、分类、聚类、降维
方法（Methods / Models） 用什么模型来解决？ 神经网络、SVM、逻辑回归、决策树、最近邻
算法（Algorithms） 如何训练/求解这个模型？ 梯度下降（GD）、随机梯度下降（SGD）、坐标下降（CD）、对偶坐标下降（Dual CD）

举例串联（图中高亮的路线）：

  • 同一个任务可以用多种方法来解决（分类可以用 SVM、决策树、神经网络……）。
  • 同一个方法可以用多种算法来训练（逻辑回归可以用梯度下降，也可以用坐标下降……）。

⚠️ 易错点：逻辑回归（Logistic Regression）名字里虽然有「回归」，但它是用来做分类的方法，不是回归任务。

📌 本部分要点速记

  1. 监督学习用带标签的数据（分类、回归）；无监督学习用不带标签的数据（聚类）；降维两种都有。
  2. 聚类：输入 n 个向量和簇数 k，输出每个样本所属的组号。
  3. 降维：把高维向量变成低维向量，用于可视化和数据预处理；常用方法有 PCA、Kernel PCA、流形学习、自编码器、LDA。
  4. 其他任务还包括排序、推荐、强化学习。
  5. 要区分三个层次：任务（解决什么问题）→ 方法（用什么模型）→ 算法（怎么训练模型）。
  6. 逻辑回归是分类方法，不要被名字误导。

（二）建模与计算

一、回顾：从数据中学习

和上一讲的图相同，只是把「函数 f」换成了「模型（Model）」：模型就是我们要从数据中学到的那个函数。

二、实践中的机器学习：建模 + 计算

机器学习在实践中由两部分组成：

建模（Modeling） 计算（Computation）
关注的问题 用什么样的模型来描述数据？ 如何求出模型的参数？
图示 各种神经网络结构（感知机、前馈网络、RNN、LSTM、自编码器等） 一个碗状的三维曲面（损失函数），要找到它的最低点
本质 设计函数的形式 优化问题：最小化损失函数

💡 简单说：建模决定「学什么」，计算决定「怎么学」。

三、建模之一：线性模型（Linear Models）

1. 特征向量

一个样本用一个 d 维的特征向量表示：

x∈Rd

以房子为例：

x=[x1x2x3⋮xd]卧室数量浴室数量面积（平方英尺）⋮房龄

2. 预测函数

f(x)=xTw

展开后就是：

f(x)=w1x1+w2x2+⋯+wdxd
  • w=[w1,w2,⋯,wd]T 称为权重（weights），也就是模型的参数
  • 每个权重 wj 表示第 j 个特征对结果的影响大小
  • 例子：输入一套房子的特征 → 预测价格 = $0.5M

3. 核心问题：如何找到 w？

训练数据（共 n 套房子）：

  • 训练特征： x1,⋯,xn∈Rd
  • 训练目标： y1,⋯,yn∈R （每套房子的真实价格）

损失函数（Loss Function）：衡量预测值和真实值之间的差距

L(w)=1n∑i=1n(xiTw−yi)2
  • xiTw ：模型对第 i 套房子的预测价格
  • yi ：第 i 套房子的真实价格
  • 对差值取平方再求平均 → 均方误差（MSE）

最小二乘回归（Least Squares Regression）：找到让损失最小的 w

w⋆=arg⁡minwL(w)

📝 幻灯片上写作 minwL(w) ，严格来说求的是取到最小值的那个 w，即 argmin。

🔗 这就把「建模」和「计算」联系起来了：建模给出 f(x)=xTw 和损失函数 L(w) ；计算负责求解 minL(w) ，也就是找到第二节图中碗状曲面的最低点。

四、超越线性模型（Beyond Linear Models）

1. 线性模型的表达能力不足

例子：根据一个人的照片预测年龄（如输出 Age = 36）。

  • 输入特征：照片的每一个像素
  • 能用线性回归吗？ 效果很差。
  • 原因：线性回归假设目标值（年龄）是照片中每个像素的加权平均。但年龄取决于皱纹、发际线、皮肤状态等复杂的视觉模式，单个像素的亮度和年龄之间几乎没有线性关系。

结论：线性模型不够有表达力（not expressive），无法处理图像这类复杂数据。

2. 传统方法：人工设计特征 + 线性模型

特征 全称 大致作用
SIFT 尺度不变特征变换 描述图像中的关键点
HOG 方向梯度直方图 描述边缘和形状
LBP 局部二值模式 描述纹理
  • 思路：先由人手工设计特征提取方法，把图片变成有意义的向量，再交给线性模型。
  • 局限：特征好不好完全依赖人的经验。

3. 卷积神经网络（CNNs）：自动学习特征

层次 学到的内容
低层特征（Low-Level） 边缘、颜色块、简单条纹
中层特征（Mid-Level） 纹理、曲线、局部形状
高层特征（High-Level） 物体的部件（如轮子、眼睛）
可训练分类器 根据高层特征给出最终判断

与传统方法的关键区别：CNN 的特征是从数据中自动学出来的，不再需要人工设计；特征提取和分类器可以一起训练。

五、CNN 的应用

1. 总体特点

  • CNN 适合处理图像数据。
  • CNN 能把图像转换成有效的表示，即完成特征提取（Feature extraction）。
  • 典型应用：
    • 图像 / 视频识别
    • 人脸识别
    • 图像生成
    • ……

2. 医疗诊断：皮肤癌诊断

  • 输入：一张皮肤病变的图片
  • 输出：
    • 是否是皮肤癌？
    • 良性（Benign）还是恶性（Malignant）？
  • 效果：准确率与人类专家相当
  • 参考文献：Esteva et al., Dermatologist-level classification of skin cancer with deep neural networks, Nature, 2017.

3. 自动驾驶

  • CNN 在自动驾驶中起重要作用：
    • 理解摄像头拍到的图像
    • 识别交通标志、车辆、行人和障碍物
  • 但 CNN 不是全部：自动驾驶是一个复杂的系统，还依赖多种传感器：
    • 激光雷达（LIDAR）、摄像头（Camera）、雷达（RADAR）
    • 超声波传感器、GPS、车轮编码器、车载单元与电子地图等

六、循环神经网络（RNNs）

1. 适用的数据

RNN 天生适合处理序列数据（sequence data），例如：

  • 时间序列数据：股票价格、天气
  • 文本数据
  • 语音数据……

序列数据的特点：数据有先后顺序，前面的内容会影响后面的内容。

2. 结构

  • xt ：第 t 个时刻的输入（如句子中的第 t 个词）
  • ht ：第 t 个时刻的输出 / 隐藏状态
  • A：同一个网络模块，在每个时刻重复使用（参数共享）
  • 左图的自环箭头表示：上一时刻的信息会传给下一时刻
  • 右图是把循环按时间展开后的样子，两者等价

💡 关键思想：RNN 有「记忆」，每一步的输出不仅取决于当前输入 xt ，还取决于之前所有步骤传递下来的信息。

3. RNN 的应用

（1）机器翻译（Machine Translation）

  • 例如：把中文「机器翻译让沟通交流变得更容易」翻译成英文 “Machine translation makes communication easier”
  • 还可以结合摄像头做拍照翻译：如把日文路牌「駐車場 24時間」翻译成 “24-hour parking”

（2）语音识别（Speech Recognition）

  • 常见的语音助手：Google 语音助手、Amazon Alexa、Microsoft Cortana、Apple Siri

七、深度强化学习（Deep Reinforcement Learning, DRL）

📝 幻灯片标题写作「DFL」，应为笔误，正确缩写是 DRL。

1. 基本思路（以游戏为例）

  • 输入：当前游戏画面
  • CNN：理解画面内容
  • 输出：选择下一步动作
  • 智能体通过不断尝试、根据得分（奖励）调整策略，逐渐学会玩游戏

这说明 DRL = 深度学习（用 CNN 等网络理解环境）+ 强化学习（通过奖励学习决策）。

2. 应用领域

  • 机器人（Robotics）
  • 电子游戏（Video game）
  • 金融（Finance）
  • 经典案例：AlphaGo（Google DeepMind）在围棋比赛中对战李世石（Lee Sedol）

八、阶段性回顾：目前学到了什么

内容 已学到的例子
机器学习任务（ML tasks） 回归、分类……
机器学习模型（ML models） 线性模型、CNN、RNN……

例子：最小二乘回归模型

  • 损失函数： L(w)=1n∑i=1n(xiTw−yi)2
  • 优化目标： w⋆=arg⁡minwL(w)

接下来的问题：如何求解这个模型？ → 这就是「计算」部分要解决的问题。

九、计算方法（Computational Methods）

  • 计算（Computations）：用数值算法来求解模型，例如：
    • 梯度下降（Gradient Descent, GD）
    • 随机梯度下降（Stochastic Gradient Descent, SGD）

📝 幻灯片写的是 “stochastic descent”，完整名称应为 stochastic gradient descent。

🔗 对应上一讲的「任务 → 方法 → 算法」三层结构：前面讲的是任务和模型，这里讲的就是算法这一层。

十、计算上的挑战（Computational Challenges）

挑战 含义 例子
大数据（Big data） 训练样本太多 ImageNet：1400 万张 256 × 256 的图片
大模型（Big model） 模型参数太多 ResNet-50（非常流行的 CNN 结构）：2500 万个参数
  • 大数据 + 大模型 带来了巨大的计算压力。
  • 例：用单块 GPU 在 ImageNet 上训练 ResNet-50，大约需要 14 天。

➡️ 结论：必须要有高效的算法和软件系统。

十一、实践中的机器学习：建模与计算分别做什么

建模（Modeling） 计算（Computation）
主要工作 选择适合数据和问题的模型 设计或使用高效的算法
决定网络结构、激活函数、损失函数等 用 TensorFlow、Hadoop 等系统实现算法
提高预测准确率 优化代码
需要的能力 对机器学习模型的经验 算法方面的经验
对问题和数据的理解 系统方面的经验

💡 一句话总结：建模追求「准」，计算追求「快」。两者结合，机器学习才能在实际中落地。

📌 本部分要点速记

  1. RNN 适合序列数据（时间序列、文本、语音），同一模块在各时刻重复使用，并把信息传给下一时刻。
  2. RNN 的典型应用：机器翻译、语音识别。
  3. 深度强化学习（DRL） = 用 CNN 理解环境 + 强化学习做决策，应用于机器人、游戏、金融，代表案例是 AlphaGo。
  4. 到目前为止学了：任务（回归、分类）和模型（线性模型、CNN、RNN）。
  5. 求解模型靠数值算法，如 GD 和 SGD。
  6. 大数据 + 大模型带来计算挑战（ResNet-50 用单 GPU 在 ImageNet 上训练约 14 天），因此需要高效的算法和系统。
  7. 建模负责提高准确率，计算负责高效实现，两者缺一不可。
